# Интерфейс модуля sites/aistudio/helpers.py

Спецификация общего UI-кода для AI Studio. Все режимы генерации (standard, multiformat) используют только функции этого модуля для кликов, ввода текста, ожидания и сохранения изображений. Прямых вызовов `pyautogui` в режимах быть не должно.

---

## 1. Роль модуля

- Общие шаги интерфейса AI Studio: поле промпта, чаты, выбор формата, запуск генерации, сохранение.
- Низкоуровневые обёртки над `pyautogui` (клик, комбинации клавиш).
- Ввод текста — только через буфер обмена и Ctrl+V, без имитации посимвольного ввода.
- Проверка готовности изображения по скриншоту области результата.

---

## 2. Низкоуровневые функции

### move_and_click

```python
def move_and_click(x: int, y: int, delay: float = 0.1) -> None
```

- **Назначение**: переместить курсор в точку (x, y) и выполнить клик.
- **Аргументы**:
  - `x`, `y` — экранные координаты в пикселях.
  - `delay` — пауза после клика (секунды).
- **Поведение**: вызов `pyautogui.moveTo`, пауза, клик, пауза `delay`.
- **Ограничения**: координаты должны быть в пределах экрана.

---

### press_keys

```python
def press_keys(*keys: str, delay: float = 0.05) -> None
```

- **Назначение**: нажать комбинацию клавиш (например, `"ctrl"`, `"v"`).
- **Аргументы**:
  - `*keys` — имена клавиш в формате pyautogui (строчные, через запятую).
  - `delay` — пауза после нажатия (секунды).
- **Поведение**: вызов `pyautogui.hotkey(*keys)`, затем `time.sleep(delay)`.
- **Пример**: `press_keys("ctrl", "v")` — вставка из буфера.

---

## 3. UI-функции AI Studio

Все функции принимают `coords: dict` — словарь с ключами координат (например, `PROMPT_INPUT`, `IMAGE_LOCATION`). Значения — кортежи `(x, y)` в пикселях.

### click_prompt_input

```python
def click_prompt_input(coords: dict) -> None
```

- **Назначение**: клик по полю ввода промпта.
- **Аргументы**: `coords` — должен содержать ключ `"PROMPT_INPUT"`.
- **Поведение**: `move_and_click` по координатам `coords["PROMPT_INPUT"]`.

---

### paste_prompt_text

```python
def paste_prompt_text(prompt_text: str, delay: float = 0.05) -> None
```

- **Назначение**: вставить текст промпта через буфер обмена и Ctrl+V (не посимвольный ввод).
- **Аргументы**:
  - `prompt_text` — строка для вставки.
  - `delay` — пауза после вставки (секунды).
- **Поведение**: записать текст в буфер обмена (через `utils.clipboard` или аналог), затем `press_keys("ctrl", "v", delay=delay)`.
- **Ограничения**: предполагается, что фокус уже в поле ввода промпта (после `click_prompt_input`).

---

### click_new_chat

```python
def click_new_chat(coords: dict) -> None
```

- **Назначение**: создать новый чат (клик по кнопке «Новый чат»).
- **Аргументы**: `coords` — ключ `"NEW_CHAT_BUTTON"`.
- **Поведение**: `move_and_click` по `coords["NEW_CHAT_BUTTON"]`.

---

### rename_chat

```python
def rename_chat(coords: dict, new_name: str) -> None
```

- **Назначение**: переименовать текущий чат.
- **Аргументы**:
  - `coords` — ключи `"CHAT_NAME_INPUT"` (и при необходимости `CHAT_NAME_POPUP`, `CHAT_NAME_CONFIRM` — по текущей логике проекта).
  - `new_name` — новое имя чата.
- **Поведение**: клик по полю названия чата, вставка `new_name` через `paste_prompt_text` (или эквивалент), нажатие Enter для подтверждения.

---

### select_aspect_ratio

```python
def select_aspect_ratio(coords: dict, ratio_text: str) -> None
```

- **Назначение**: выбрать соотношение сторон изображения (4:3, 3:2 и т.п.) через выпадающий список.
- **Аргументы**:
  - `coords` — ключ `"ASPECT_RATIO_SELECTOR"` (или `FORMAT_SELECTOR` по текущему проекту).
  - `ratio_text` — строка формата, например `"4:3"`, `"3:2"`.
- **Поведение**: клик по селектору, ввод `ratio_text`, Enter. Используется только в мультиформатном режиме.

---

### start_generation

```python
def start_generation() -> None
```

- **Назначение**: запустить генерацию изображения (обычно Ctrl+Enter в AI Studio).
- **Аргументы**: нет (координаты не нужны).
- **Поведение**: `press_keys("ctrl", "enter")`. Фокус должен быть в поле промпта.

---

### save_image

```python
def save_image(coords: dict, file_name: str) -> None
```

- **Назначение**: сохранить сгенерированное изображение через контекстное меню (клик по области изображения → пункт «Сохранить» и т.п.).
- **Аргументы**:
  - `coords` — ключи `"IMAGE_LOCATION"` и при необходимости относительные смещения к пункту «Сохранить» (например, `TO_SAVE_OPTION`).
  - `file_name` — имя файла для сохранения (без пути или с путём — по соглашению проекта).
- **Поведение**: клик по `IMAGE_LOCATION` (открытие контекстного меню), перемещение к пункту сохранения (если нужно), клик, ввод имени файла при необходимости. Детали — по текущей реализации в проекте (window_manager, координаты).

## 4. Проверка готовности изображения по скриншоту

Тип изображения: `PIL.Image.Image` (из `PIL` / `pillow`), либо объект, возвращаемый `pyautogui.screenshot()`.

### grab_result_area

```python
def grab_result_area(coords: dict, box_size: tuple[int, int]) -> Image
```

- **Назначение**: сделать скриншот прямоугольной области вокруг точки результата изображения.
- **Аргументы**:
  - `coords` — ключ `"IMAGE_LOCATION"` (x, y центра области).
  - `box_size` — (width, height) области в пикселях.
- **Возвращает**: изображение области (PIL Image или аналог).
- **Поведение**: вычислить left/top так, чтобы центр был в `IMAGE_LOCATION`, сделать `pyautogui.screenshot(region=(...))` и вернуть результат.

---

### compute_difference_score

```python
def compute_difference_score(img1: Image, img2: Image) -> float
```

- **Назначение**: вычислить числовую оценку отличия двух изображений (одного размера).
- **Аргументы**: `img1`, `img2` — изображения той же области в разные моменты времени.
- **Возвращает**: неотрицательное число; чем больше — тем сильнее отличие.
- **Поведение**: например, через `PIL.ImageChops.difference` и усреднение по каналам, либо сумма абсолютных разностей пикселей. Конкретная формула — на усмотрение реализации; важно, что при появлении новой картинки значение заметно вырастает.

---

### wait_until_image_ready

```python
def wait_until_image_ready(
    coords: dict,
    timeout_seconds: float,
    check_interval: float,
    box_size: tuple[int, int],
    diff_threshold: float,
) -> bool
```

- **Назначение**: ждать до таймаута или пока область результата заметно изменится относительно начального скрина (появление сгенерированного изображения).
- **Аргументы**:
  - `coords` — словарь с `IMAGE_LOCATION`.
  - `timeout_seconds` — максимальное время ожидания (секунды).
  - `check_interval` — пауза между проверками (секунды).
  - `box_size` — размер области для скриншота (width, height).
  - `diff_threshold` — порог: если `compute_difference_score(base, current) >= diff_threshold`, считаем, что изображение готово.
- **Возвращает**:
  - `True` — область изменилась достаточно (картинка, по предположению, сгенерирована).
  - `False` — истекло время `timeout_seconds` без превышения порога.
- **Поведение**: один раз снять базовый скрин области; в цикле с интервалом `check_interval` снимать новый скрин, считать разницу с базовым; при достижении порога вернуть `True`; при достижении таймаута вернуть `False`. Подпроцесс не проверяет флаги остановки — только таймаут и порог.

## 5. Зависимости модуля

- `pyautogui` — клики, перемещение, скриншоты, горячие клавиши.
- `time` — паузы.
- Модуль/функция работы с буфером обмена (например, `utils.clipboard.set_clipboard_text` или аналог в v2).
- Для `compute_difference_score` и, при необходимости, конвертации скриншотов — `PIL` (Pillow): `ImageChops`, `ImageStat` и т.п.

---

## 6. Ошибки и ограничения

- При отсутствии ключа в `coords` реализация может бросать `KeyError` или возвращать понятное сообщение — в интерфейсе не оговаривается жёстко.
- Функции не принимают и не проверяют флаг остановки (экстренная остановка — только через завершение подпроцесса извне).
- `save_image` зависит от текущей схемы координат проекта (контекстное меню, диалоги сохранения); при переносе в v2 при необходимости уточнить ключи в `coords`.
