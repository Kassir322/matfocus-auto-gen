# Правила именования чатов и файлов

Стандарты формирования имён чатов в AI Studio и файлов сохраняемых изображений.

---

## 1. Общие правила

### 1.1. Безопасные символы

При формировании имён заменяются:

- Пробелы ` ` → `_`
- Слэши `/` и `\` → `_`
- Двоеточие `:` → `x` (для соотношений сторон)

Удаляются:

- Символы: `*`, `?`, `"`, `<`, `>`, `|`

### 1.2. Функция преобразования

```python
def safe_name(text):
    """
    Преобразует текст в безопасное имя для файла/чата.
    """
    safe = text.replace(" ", "_").replace("/", "_").replace("\\", "_")
    for char in ['*', '?', '"', '<', '>', '|']:
        safe = safe.replace(char, '')
    return safe

def safe_format(ratio):
    """
    Преобразует соотношение сторон в безопасную строку.
    Пример: "4:3" → "4x3"
    """
    return ratio.replace(":", "x")
```

## 2. Режим standard

### 2.1. Имя чата

```
Карточка {card_number} - {card_name} - генерация {gen_num}
```

**Примеры**:
| card_number | card_name | gen_num | Имя чата |
|-------------|-----------|---------|----------|
| 1 | Карточка 1 | 1 | `Карточка 1 - Карточка 1 - генерация 1` |
| 1 | Карточка 1 | 2 | `Карточка 1 - Карточка 1 - генерация 2` |
| 5 | Карточка 5 | 1 | `Карточка 5 - Карточка 5 - генерация 1` |

**Примечание**: В стандартном режиме `card_name` всегда = `Карточка {N}`, поэтому дублируется.

### 2.2. Имя файла

```
Карточка_{card_number}_генерация_{gen_num}.png
```

**Примеры**:
| card*number | gen_num | Имя файла |
|-------------|---------|-----------|
| 1 | 1 | `Карточка_1*генерация*1.png`|
| 1 | 2 |`Карточка_1*генерация*2.png`|
| 5 | 3 |`Карточка_5*генерация_3.png` |

## 3. Режим multiformat

### 3.1. Имя чата

```
Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}
```

**Примеры**:
| card_number | card_name | side | pair_number | Имя чата |
|-------------|-----------|------|-------------|----------|
| 63 | Нефть | лицо | 1 | `Карточка 63 - Нефть - лицо - Промпт 1` |
| 63 | Нефть | оборот | 1 | `Карточка 63 - Нефть - оборот - Промпт 1` |
| 20 | Балтийское море | лицо | 2 | `Карточка 20 - Балтийское море - лицо - Промпт 2` |

### 3.2. Имя файла

```
Карточка_{card_number}_{safe_card_name}_{side}_промпт_{pair_number}_{safe_format}.png
```

**Примеры**:
| Входные данные | Имя файла |
|----------------|-----------|
| card=63, name=Нефть, side=лицо, pair=1, format=4:3 | `Карточка_63_Нефть_лицо_промпт_1_4x3.png` |
| card=63, name=Нефть, side=оборот, pair=1, format=3:2 | `Карточка_63_Нефть_оборот_промпт_1_3x2.png` |
| card=20, name=Балтийское море, side=лицо, pair=1, format=4:3 | `Карточка_20_Балтийское_море_лицо_промпт_1_4x3.png` |

## 4. Режим multiformat_with_refs

### 4.1. Имя чата

Такое же, как в `multiformat`:

```
Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}
```

Референс **не отражается** в имени чата.

### 4.2. Имя файла

Такое же, как в `multiformat`:

```
Карточка_{card_number}_{safe_card_name}_{side}_промпт_{pair_number}_{safe_format}.png
```

Референс **не отражается** в имени файла.

### 5.2. Имя файла референса


## 7. Код формирования имён

### 7.1. Для standard

```python
def make_chat_name_standard(card_number, card_name, gen_num):
    """Формирует имя чата для стандартного режима."""
    return f"Карточка {card_number} - {card_name} - генерация {gen_num}"

def make_filename_standard(card_number, gen_num):
    """Формирует имя файла для стандартного режима."""
    return f"Карточка_{card_number}_генерация_{gen_num}.png"
```

### 7.2. Для multiformat

```python
def make_chat_name_multiformat(card_number, card_name, side, pair_number):
    """Формирует имя чата для мультиформатного режима."""
    return f"Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}"

def make_filename_multiformat(card_number, card_name, side, pair_number, format_ratio):
    """Формирует имя файла для мультиформатного режима."""
    safe_card_name = safe_name(card_name)
    safe_fmt = safe_format(format_ratio)
    return f"Карточка_{card_number}_{safe_card_name}_{side}_промпт_{pair_number}_{safe_fmt}.png"
```

### 7.3. Для референсов

```python
def make_reference_filename(side, card_number, card_name, ext="png"):
    """Формирует ожидаемое имя файла референса."""
    safe_card_name = safe_name(card_name)
    return f"{side}_{card_number}_{safe_card_name}.{ext}"
```

## 8. Ограничения

### 8.1. Длина имени файла

Windows ограничивает путь до **260 символов** (или **32767** с длинными путями).

Если имя слишком длинное:

- Сокращается `card_name` (первые 30 символов)
- Логируется предупреждение

### 8.2. Кириллица

Кириллица **поддерживается** в именах файлов и чатов:

- Кодировка UTF-8
- Windows NTFS поддерживает кириллицу
