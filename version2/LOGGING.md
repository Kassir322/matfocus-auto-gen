# Логирование v2

Правила вывода информации: куда пишем и в каком виде.

---

## 1. Два канала вывода

| Канал | Назначение |
|-------|------------|
| **Файл** в папке `logs/` | Полное логирование: все шаги, теги, детали. Один файл на запуск программы. |
| **Консоль** | Только супер основные шаги: старт, прогресс по карточкам, завершение или остановка. |

Подробные логи пишутся **только в файл**. В консоль — минимум.

### 1.1. Имя файла лога

При **запуске программы** создаётся **новый** файл лога. Имя файла содержит дату и время запуска **до секунды**:

```
logs/auto-gen_YYYY-MM-DD_HH-MM-SS.log
```

Примеры:
- `logs/auto-gen_2024-01-15_10-30-00.log` — запуск 15 января 2024, 10:30:00
- `logs/auto-gen_2024-01-15_14-05-33.log` — запуск в 14:05:33

Файл создаётся в момент старта (при инициализации логирования), все логи за сессию пишутся в него.

---

## 2. Консоль: что выводить

- Запуск генерации: «Генерация запущена. Esc — остановка.»
- Текущий прогресс: «Карточка 3 из 10» (или «Генерация 5 из 24» для standard)
- Завершение: «Готово. Обработано карточек: 10, генераций: 24»
- Остановка по Esc: «Остановлено пользователем.»

Ошибки, блокирующие старт (нет файла, нет координат), можно выводить в консоль.

---

## 3. Файл: теги (без эмодзи)

Эмодзи в логах **не допускаются**. Используются короткие теги капсом (1–2 слова).

| Тег | Значение | Пример строки в файле |
|-----|----------|------------------------|
| `[PLAN]` | План перед стартом | `[PLAN] Режим: standard. Карточек: 10, генераций: 24` |
| `[CARD]` | Начало карточки | `[CARD] Карточка 3` |
| `[PAIR]` | Начало пары (multiformat) | `[PAIR] Карточка 5, пара 2` |
| `[SIDE]` | Сторона (лицо/оборот) | `[SIDE] лицо, промпт 1` |
| `[GEN]` | Начало одной генерации | `[GEN] Карточка 1 - генерация 2` |
| `[OK]` | Успех (сохранение и т.п.) | `[OK] Файл сохранён: Карточка_1_лицевая_промпт_1.png` |
| `[WARN]` | Предупреждение | `[WARN] Пропуск лицевой стороны (промпт отсутствует)` |
| `[ERROR]` | Ошибка | `[ERROR] Ошибка при сохранении файла: ...` |
| `[REF]` | Референс (вставлен/проверка) | `[REF] Вставлен референс: data/images/лицо/...` |
| `[CHECK]` | Проверка (референсы и т.д.) | `[CHECK] Референсы: 20/20 найдено` |
| `[SUMMARY]` | Итоги | `[SUMMARY] Карточек: 10, пар: 10, изображений: 20` |

## 4. Примеры

### Консоль (минимально)

```
Генерация запущена. Esc — остановка.
Карточка 2 из 10
Карточка 5 из 10
Готово. Обработано карточек: 10, генераций: 24
```

### Файл (фрагмент)

```
2024-01-15 10:30:00 [PLAN] Режим: standard. Файл: data/prompts.txt. Карточек: 10, генераций: 24
2024-01-15 10:30:01 [CARD] Карточка 1
2024-01-15 10:30:01 [GEN] Карточка 1 - генерация 1
2024-01-15 10:30:25 [OK] Файл сохранён: Карточка_1_лицевая_промпт_1.png
2024-01-15 10:30:26 [GEN] Карточка 1 - генерация 2
2024-01-15 10:30:50 [OK] Файл сохранён: Карточка_1_лицевая_промпт_2.png
2024-01-15 10:30:52 [CARD] Карточка 2
...
2024-01-15 10:45:00 [SUMMARY] Карточек: 10, генераций: 24
```

## 5. Реализация

- **При старте программы**: сформировать имя файла `logs/auto-gen_{дата}_{время}.log`, где дата `YYYY-MM-DD`, время `HH-MM-SS` (момент запуска). Создать папку `logs/` при отсутствии. Открыть файл на запись и передать его в `FileHandler`.
- Один логгер с `FileHandler` на этот файл (полные логи с тегами). В консоль — только «основные» сообщения (отдельно, например через `print` или второй обработчик с фильтром).
- Формат строки в файле: `%(asctime)s %(message)s` (тег уже в message, например `[PLAN] ...`).

Пример формирования имени в коде:

```python
from datetime import datetime
import os

def get_log_filepath():
    os.makedirs("logs", exist_ok=True)
    timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
    return os.path.join("logs", f"auto-gen_{timestamp}.log")
```

Теги всегда в квадратных скобках, капсом, без эмодзи.
