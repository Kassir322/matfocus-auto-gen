# Формат референсных изображений

Описание структуры папок и правил именования файлов референсов для режима `multiformat_with_refs`.

---

## 1. Общее описание

Референсные изображения — это локальные файлы (PNG или JPG), которые вставляются в чат **перед промптом** для того, чтобы нейросеть учитывала их при генерации.

Каждому промпту соответствует **один референс** (или ни одного).

---

## 2. Структура папок

```
data/
└── images/
    ├── лицо/
    │   ├── 3_лицо.png           (упрощенный формат)
    │   ├── 11_лицо.png          (упрощенный формат)
    │   ├── 20_лицо.jpg          (упрощенный формат)
    │   ├── лицо_1_Карточка_1.png  (полный формат, опционально)
    │   └── ...
    │
    └── оборот/
        ├── 3_оборот.png         (упрощенный формат)
        ├── 11_оборот.png        (упрощенный формат)
        ├── 20_оборот.jpg        (упрощенный формат)
        ├── оборот_1_Карточка_1.png  (полный формат, опционально)
        └── ...
```

**Важно**:

- Папка `лицо/` содержит референсы для лицевой стороны.
- Папка `оборот/` содержит референсы для оборотной стороны.
- Названия папок — **кириллица**, строчные буквы.
- Можно использовать **любой из двух форматов** или смешивать их.

---

## 3. Формат имени файла

Поддерживаются **два формата** имён файлов референсов:

### 3.1. Упрощенный формат (рекомендуется)

```
{номер_карточки}_{сторона}.{расширение}
```

| Компонент           | Описание                | Пример   |
| ------------------- | ----------------------- | -------- |
| `{номер_карточки}`  | Номер карточки          | `20`     |
| `_{сторона}`        | `"лицо"` или `"оборот"` | `_лицо`  |
| `.{расширение}`     | `png` или `jpg`         | `.png`   |

**Примеры**:

```
3_лицо.png
11_лицо.png
17_оборот.jpg
20_лицо.png
```

**Преимущества**: Проще именовать, не требуется совпадение названия карточки с файлом промптов.

### 3.2. Полный формат (опциональный, для обратной совместимости)

```
{сторона}_{номер_карточки}_{название_карточки}.{расширение}
```

| Компонент              | Описание                           | Пример             |
| ---------------------- | ---------------------------------- | ------------------ |
| `{сторона}`            | `"лицо"` или `"оборот"`            | `лицо`             |
| `_{номер_карточки}`    | Номер карточки через `_`           | `_20`              |
| `_{название_карточки}` | Название с заменой пробелов на `_` | `_Балтийское_море` |
| `.{расширение}`        | `png` или `jpg`                    | `.png`             |

**Примеры**:

```
лицо_20_Балтийское_море.png
оборот_63_Нефть.jpg
```

**Когда использовать**: Если нужно включить название карточки в имя файла для лучшей организации.

---

## 4. Правила преобразования названия

При формировании имени файла из названия карточки:

1. **Пробелы** заменяются на `_`
2. **Слэши** `/` и `\` заменяются на `_`
3. **Другие спецсимволы** (`:`, `*`, `?`, `"`, `<`, `>`, `|`) удаляются или заменяются
4. **Регистр** сохраняется (не приводится к нижнему)

```python
def safe_filename(name):
    """
    Преобразует название карточки в безопасное имя файла.
    """
    # Заменяем пробелы и слэши на подчеркивания
    safe = name.replace(" ", "_").replace("/", "_").replace("\\", "_")

    # Убираем недопустимые символы Windows
    for char in [':', '*', '?', '"', '<', '>', '|']:
        safe = safe.replace(char, '')

    return safe
```

**Примеры**:
| Название карточки | Имя файла |
|-------------------|-----------|
| `Балтийское море` | `лицо_20_Балтийское_море.png` |
| `Нефть` | `лицо_63_Нефть.png` |
| `Карточка 1` | `лицо_1_Карточка_1.png` |
| `Порт/Гавань` | `лицо_5_Порт_Гавань.png` |

## 5. Поддерживаемые форматы

| Расширение | Поддержка                     |
| ---------- | ----------------------------- |
| `.png`     | ✓ Да (предпочтительно)        |
| `.jpg`     | ✓ Да                          |
| `.jpeg`    | ✗ Нет (переименуйте в `.jpg`) |
| `.gif`     | ✗ Нет                         |
| `.webp`    | ✗ Нет                         |
| `.bmp`     | ✗ Нет                         |

При поиске файла проверяются **оба расширения** (png, затем jpg).

## 6. Алгоритм поиска референса

Функция `get_reference_path()` ищет референс в **два этапа** с приоритетом упрощенного формата:

```python
import os

def get_reference_path(side, card_number, card_name):
    """
    Ищет файл референса для указанной стороны и карточки.
    Поддерживает два формата:
    1. Простой: {номер}_{сторона}.{ext}  (приоритет)
    2. Полный: {сторона}_{номер}_{название}.{ext}  (запасной)

    Аргументы:
        side: "лицо" или "оборот"
        card_number: номер карточки (int)
        card_name: название карточки (str)

    Возвращает:
        str: путь к файлу, если найден
        None: если не найден
    """
    base_folder = os.path.join("data", "images", side)
    
    # Этап 1: Ищем упрощенный формат (приоритет)
    for ext in ["png", "jpg"]:
        filename = f"{card_number}_{side}.{ext}"
        full_path = os.path.join(base_folder, filename)
        if os.path.exists(full_path):
            return full_path
    
    # Этап 2: Ищем полный формат (запасной, для обратной совместимости)
    safe_name = safe_filename(card_name)
    for ext in ["png", "jpg"]:
        filename = f"{side}_{card_number}_{safe_name}.{ext}"
        full_path = os.path.join(base_folder, filename)
        if os.path.exists(full_path):
            return full_path
    
    # Не найден
    return None
```

**Порядок поиска**:
1. Сначала `3_лицо.png`, `3_лицо.jpg`
2. Затем `лицо_3_Олег_Вещий.png`, `лицо_3_Олег_Вещий.jpg`

## 7. Проверка наличия референсов

Перед началом генерации выполняется проверка:

```python
def check_all_references(parsed_data):
    """
    Проверяет наличие всех необходимых референсов.

    Возвращает:
        dict: {
            "found": [(side, card_num, card_name, path), ...],
            "missing": [(side, card_num, card_name, expected_name), ...]
        }
    """
    found = []
    missing = []

    for card_num, card_data in parsed_data.items():
        card_name = card_data["name"]

        for pair in card_data["pairs"]:
            for side in ["лицо", "оборот"]:
                if pair[side] is not None:  # Есть промпт для этой стороны
                    path = get_reference_path(side, card_num, card_name)

                    if path:
                        found.append((side, card_num, card_name, path))
                    else:
                        safe_name = safe_filename(card_name)
                        expected = f"{side}_{card_num}_{safe_name}.png/.jpg"
                        missing.append((side, card_num, card_name, expected))

    return {"found": found, "missing": missing}
```

Вывод в консоль:

```

✓ Найдено: 38/40
⚠️ Отсутствуют референсы:
  - лицо карточки 15 (Порт) — ожидается: лицо_15_Порт.png/.jpg
  - оборот карточки 23 (Завод) — ожидается: оборот_23_Завод.png/.jpg

Продолжить без них? (y/n):
```

## 8. Требования к изображениям

| Параметр              | Рекомендация                                   |
| --------------------- | ---------------------------------------------- |
| Размер                | 512×512 — 2048×2048 px                         |
| Соотношение сторон    | Любое (лучше соответствовать целевому формату) |
| Цветовое пространство | RGB (не CMYK)                                  |
| Глубина цвета         | 8 бит                                          |
| Прозрачность          | Допускается для PNG (будет заменена на белый)  |

## 9. Пример подготовки референсов

**Задача**: подготовить референсы для карточек 63 (Нефть) и 20 (Балтийское море).

**Шаги**:

1. Создать папки:

   ```
   data/images/лицо/
   data/images/оборот/
   ```

2. Подготовить изображения и переименовать:

   ```
   лицо_63_Нефть.png
   оборот_63_Нефть.png
   лицо_20_Балтийское_море.png
   оборот_20_Балтийское_море.png
   ```

3. Разложить по папкам:

   ```
   data/images/лицо/лицо_63_Нефть.png
   data/images/лицо/лицо_20_Балтийское_море.png
   data/images/оборот/оборот_63_Нефть.png
   data/images/оборот/оборот_20_Балтийское_море.png
   ```

4. Запустить генерацию — программа найдёт референсы автоматически.

## 10. Частые ошибки

| Ошибка             | Причина                     | Решение                                                        |
| ------------------ | --------------------------- | -------------------------------------------------------------- |
| Референс не найден | Неверное имя файла          | Проверить формат имени                                         |
| Референс не найден | Файл в корне `data/images/` | Переместить в подпапку `лицо/` или `оборот/`                   |
| Референс не найден | Расширение `.jpeg`          | Переименовать в `.jpg`                                         |
| Референс не найден | Пробелы в имени файла       | Заменить пробелы на `_`                                        |
| Референс не найден | Название не совпадает       | Название в файле должно совпадать с названием в файле промптов |
| Ошибка вставки     | Повреждённый файл           | Пересохранить изображение                                      |

---

## 11. Связь с файлом промптов

Название карточки в файле референса **должно точно совпадать** с названием в файле промптов (после преобразования `safe_filename`).

**Файл промптов**:

```
Карточка 20 лицо Балтийское море - Промпт 1: ...
```

**Файл референса**:

```
лицо_20_Балтийское_море.png
```

Если название в промптах `"Балтийское море"`, а файл называется `лицо_20_Балтийское море.png` (с пробелом) — **не найдётся**.
