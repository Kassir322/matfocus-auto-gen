# Список ключей координат

Полный справочник всех координат и относительных движений, используемых в программе.

---

## 1. Два типа координат

В программе используются **два словаря** координат:

| Словарь              | Тип           | Описание                             |
| -------------------- | ------------- | ------------------------------------ |
| `coordinates`        | Абсолютные    | Точка на экране (x, y)               |
| `relative_movements` | Относительные | Смещение от текущей позиции (dx, dy) |

Хранятся в `data/coordinates.json`.

---

## 2. Абсолютные координаты (`coordinates`)

### 2.1. Базовые (для всех режимов)

| Ключ              | Описание                                                    | Режимы |
| ----------------- | ----------------------------------------------------------- | ------ |
| `PROMPT_INPUT`    | Поле ввода промпта                                          | Все    |
| `IMAGE_LOCATION`  | Место клика на сгенерированное изображение (для сохранения) | Все    |
| `NEW_CHAT_BUTTON` | Кнопка создания нового чата                                 | Все    |
| `CHAT_NAME_INPUT` | Поле ввода названия чата (первый клик)                      | Все    |

### 2.2. Для попапа переименования (опционально)

| Ключ                | Описание                           | Режимы                |
| ------------------- | ---------------------------------- | --------------------- |
| `CHAT_NAME_POPUP`   | Поле ввода в попапе переименования | Все (если есть попап) |
| `CHAT_NAME_CONFIRM` | Кнопка подтверждения в попапе      | Все (если есть попап) |

### 2.3. Для мультиформатного режима

| Ключ                    | Описание                                    | Режимы                                 |
| ----------------------- | ------------------------------------------- | -------------------------------------- |
| `ASPECT_RATIO_SELECTOR` | Выпадающий список выбора соотношения сторон | `multiformat`, `multiformat_with_refs` |

### 2.4. Для режима с референсами

| Ключ                       | Описание                                         | Режимы                  |
| -------------------------- | ------------------------------------------------ | ----------------------- |
| `PROMPT_INPUT_AFTER_IMAGE` | Поле ввода промпта **после** вставки изображения | `multiformat_with_refs` |

---

## 3. Относительные движения (`relative_movements`)

| Ключ             | Описание                                                          | Режимы |
| ---------------- | ----------------------------------------------------------------- | ------ |
| `TO_SAVE_OPTION` | Смещение от правого клика к пункту "Сохранить изображение как..." | Все    |

**Как работает**:

1. Правый клик по `IMAGE_LOCATION` открывает контекстное меню.
2. Курсор перемещается на (dx, dy) относительно текущей позиции.
3. Левый клик выбирает пункт меню.

---

## 4. Требования по режимам

### 4.1. Режим `standard`

**Обязательные координаты**:

- `PROMPT_INPUT`
- `IMAGE_LOCATION`
- `NEW_CHAT_BUTTON`
- `CHAT_NAME_INPUT`
- `TO_SAVE_OPTION`

**Опциональные**:

- `CHAT_NAME_POPUP`
- `CHAT_NAME_CONFIRM`

### 4.2. Режим `multiformat`

**Обязательные координаты**:

- Все из `standard`
- `ASPECT_RATIO_SELECTOR`

### 4.3. Режим `multiformat_with_refs`

**Обязательные координаты**:

- Все из `multiformat`
- `PROMPT_INPUT_AFTER_IMAGE`

## 5. Значения по умолчанию

```python
default_coordinates = {
    'PROMPT_INPUT': (0, 0),
    'IMAGE_LOCATION': (0, 0),
    'NEW_CHAT_BUTTON': (0, 0),
    'CHAT_NAME_INPUT': (0, 0),
    'CHAT_NAME_POPUP': (0, 0),
    'CHAT_NAME_CONFIRM': (0, 0),
    'ASPECT_RATIO_SELECTOR': (0, 0),
    'PROMPT_INPUT_AFTER_IMAGE': (0, 0),
}

default_relative_movements = {
    'TO_SAVE_OPTION': (0, 0),
}
```

Координата `(0, 0)` означает "не задана".

## 6. Формат хранения (coordinates.json)

```json
{
	"coordinates": {
		"PROMPT_INPUT": [1234, 567],
		"IMAGE_LOCATION": [890, 123],
		"NEW_CHAT_BUTTON": [456, 789],
		"CHAT_NAME_INPUT": [111, 222],
		"CHAT_NAME_POPUP": [0, 0],
		"CHAT_NAME_CONFIRM": [0, 0],
		"ASPECT_RATIO_SELECTOR": [333, 444],
		"PROMPT_INPUT_AFTER_IMAGE": [555, 666]
	},
	"relative_movements": {
		"TO_SAVE_OPTION": [50, 120]
	}
}
```

## 7. Проверка перед запуском

Перед началом генерации проверяются **обязательные** координаты для выбранного режима:

```python
def check_required_coordinates(mode, coordinates, relative_movements):
    """
    Проверяет наличие обязательных координат.

    Возвращает:
        list: список отсутствующих координат (пустой = все ОК)
    """
    required = {
        'standard': [
            'PROMPT_INPUT',
            'IMAGE_LOCATION',
            'NEW_CHAT_BUTTON',
            'CHAT_NAME_INPUT',
        ],
        'multiformat': [
            'PROMPT_INPUT',
            'IMAGE_LOCATION',
            'NEW_CHAT_BUTTON',
            'CHAT_NAME_INPUT',
            'ASPECT_RATIO_SELECTOR',
        ],
        'multiformat_with_refs': [
            'PROMPT_INPUT',
            'IMAGE_LOCATION',
            'NEW_CHAT_BUTTON',
            'CHAT_NAME_INPUT',
            'ASPECT_RATIO_SELECTOR',
            'PROMPT_INPUT_AFTER_IMAGE',
        ],
    }

    # Всегда проверяем относительное движение
    required_movements = ['TO_SAVE_OPTION']

    missing = []

    for key in required.get(mode, []):
        if coordinates.get(key, (0, 0)) == (0, 0):
            missing.append(key)

    for key in required_movements:
        if relative_movements.get(key, (0, 0)) == (0, 0):
            missing.append(key)

    return missing
```

Вывод при ошибке:

```
❌ Отсутствуют обязательные координаты:
  - ASPECT_RATIO_SELECTOR
  - TO_SAVE_OPTION

Настройте их через Ctrl+0.
```

## 9. Описания координат

| Ключ                       | Где находится                      | Как найти                                      |
| -------------------------- | ---------------------------------- | ---------------------------------------------- |
| `PROMPT_INPUT`             | Текстовое поле внизу чата          | Кликните в центр поля ввода                    |
| `IMAGE_LOCATION`           | Центр сгенерированного изображения | После генерации наведите на изображение        |
| `NEW_CHAT_BUTTON`          | Кнопка "+" или "New chat"          | Обычно в левой панели                          |
| `CHAT_NAME_INPUT`          | Название чата в списке             | Кликните по тексту названия текущего чата      |
| `CHAT_NAME_POPUP`          | Поле в модальном окне              | Если есть попап — в центре поля                |
| `CHAT_NAME_CONFIRM`        | Кнопка OK/Confirm                  | В попапе переименования                        |
| `ASPECT_RATIO_SELECTOR`    | Выпадающий список формата          | Рядом с полем промпта                          |
| `PROMPT_INPUT_AFTER_IMAGE` | Поле ввода после картинки          | После вставки референса — в поле под картинкой |
| `TO_SAVE_OPTION`           | Пункт контекстного меню            | Смещение от ПКМ до "Сохранить как..."          |

---

## 10. Добавление новых координат

При добавлении новой координаты:

1. Добавить в `default_coordinates` или `default_relative_movements`.
2. Обновить функцию проверки `check_required_coordinates`.
3. Обновить меню настройки координат.
4. Обновить этот документ.
