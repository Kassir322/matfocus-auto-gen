# Руководство по настройке координат

Пошаговая инструкция по настройке координат элементов интерфейса AI Studio.

---

## 1. Общий принцип

Координаты — это точки на экране (X, Y), по которым программа будет кликать при автоматизации. Каждая координата соответствует определённому элементу интерфейса AI Studio.

**Важно**: Координаты привязаны к **разрешению экрана** и **положению окна браузера**. При изменении масштаба, разрешения или перемещении окна координаты нужно настроить заново.

---

## 2. Горячие клавиши для настройки

| Горячая клавиша | Действие                                       |
| --------------- | ---------------------------------------------- |
| `Ctrl+0`        | Открыть меню выбора координаты                 |
| `Ctrl+Shift+P`  | Захватить координату курсора                   |
| `Ctrl+Shift+V`  | Настройка окна браузера (найти и активировать) |

---

## 3. Процесс настройки одной координаты

### Шаг 1: Открыть меню

Нажмите `Ctrl+0`. Появится меню:

```
------------------------------------------------------------
МЕНЮ НАСТРОЙКИ КООРДИНАТ
------------------------------------------------------------
=== КООРДИНАТЫ ===
  PROMPT_INPUT: (0, 0) - ⚠️ не задана
  IMAGE_LOCATION: (0, 0) - ⚠️ не задана
  ...
=== ОТНОСИТЕЛЬНЫЕ ДВИЖЕНИЯ ===
  TO_SAVE_OPTION: (0, 0) - ⚠️ не задано
------------------------------------------------------------
Выберите координату для настройки:
  1. PROMPT_INPUT - Поле ввода промпта [⚠️ не задана]
  2. IMAGE_LOCATION - Место клика на сгенерированное изображение [⚠️ не задана]
  ...
  0. Отмена
------------------------------------------------------------
Введите номер координаты:
```

### Шаг 2: Выбрать координату

Введите номер координаты (например, `1` для `PROMPT_INPUT`) и нажмите Enter.

```
Выбрана координата: PROMPT_INPUT
Описание: Поле ввода промпта
Наведите курсор на нужный элемент и нажмите Ctrl+Shift+P
```

### Шаг 3: Навести курсор

1. Переключитесь на окно браузера с AI Studio.
2. Наведите курсор **точно** на нужный элемент.
3. **Не двигайте** курсор.

### Шаг 4: Захватить координату

Нажмите `Ctrl+Shift+P`. Программа запомнит текущее положение курсора.

```
✓ Координата PROMPT_INPUT обновлена: (1234, 567)
✓ Координата установлена и сохранена!
```

Координаты автоматически сохраняются в `data/coordinates.json`.

## 4. Настройка всех координат (пошагово)

### 4.1. Подготовка

1. Откройте AI Studio в браузере.
2. Расположите окно так, как будет во время работы.
3. **Не меняйте** размер и положение окна после настройки.

### 4.2. Базовые координаты (обязательные)

#### PROMPT_INPUT — Поле ввода промпта

**Где искать**: Текстовое поле внизу чата, куда вводится промпт.

**Как настроить**:

1. `Ctrl+0` → выбрать `PROMPT_INPUT`
2. Навести курсор на **центр** поля ввода
3. `Ctrl+Shift+P`

#### IMAGE_LOCATION — Сгенерированное изображение

**Где искать**: Область, где появляется сгенерированное изображение.

**Как настроить**:

1. Сначала сгенерируйте любое изображение вручную
2. `Ctrl+0` → выбрать `IMAGE_LOCATION`
3. Навести курсор на **центр** изображения
4. `Ctrl+Shift+P`

#### NEW_CHAT_BUTTON — Кнопка нового чата

**Где искать**: Обычно кнопка "+" или "New chat" в левой панели.

**Как настроить**:

1. `Ctrl+0` → выбрать `NEW_CHAT_BUTTON`
2. Навести курсор на кнопку создания чата
3. `Ctrl+Shift+P`

#### CHAT_NAME_INPUT — Поле названия чата

**Где искать**: Название текущего чата в списке слева (или вверху).

**Как настроить**:

1. `Ctrl+0` → выбрать `CHAT_NAME_INPUT`
2. Навести курсор на текст названия активного чата
3. `Ctrl+Shift+P`

#### TO_SAVE_OPTION — Пункт "Сохранить как..."

**Особенность**: Это **относительное движение** (смещение), а не абсолютная координата.

**Как настроить**:

1. Правой кнопкой кликните на сгенерированное изображение
2. Откроется контекстное меню
3. **Не закрывая меню**, посмотрите, где находится пункт "Сохранить изображение как..."
4. `Ctrl+0` → выбрать `TO_SAVE_OPTION`
5. Наведите курсор на пункт "Сохранить изображение как..."
6. `Ctrl+Shift+P`

**Как это работает**:

- Программа запоминает смещение от точки клика до пункта меню.
- При работе: ПКМ по `IMAGE_LOCATION` → переместить курсор на (dx, dy) → ЛКМ.

### 4.3. Координаты для мультиформатного режима

#### ASPECT_RATIO_SELECTOR — Выбор соотношения сторон

**Где искать**: Выпадающий список или кнопка выбора формата изображения (обычно рядом с полем промпта).

**Как настроить**:

1. `Ctrl+0` → выбрать `ASPECT_RATIO_SELECTOR`
2. Навести курсор на элемент выбора формата
3. `Ctrl+Shift+P`

### 4.4. Координаты для режима с референсами

#### PROMPT_INPUT_AFTER_IMAGE — Поле ввода после картинки

**Особенность**: После вставки референса интерфейс может измениться.

**Как настроить**:

1. Вставьте любое изображение в чат вручную (Ctrl+V)
2. Обратите внимание, где теперь находится поле ввода промпта
3. `Ctrl+0` → выбрать `PROMPT_INPUT_AFTER_IMAGE`
4. Навести курсор на поле ввода (под вставленной картинкой)
5. `Ctrl+Shift+P`

### 4.5. Опциональные координаты

#### CHAT_NAME_POPUP — Попап переименования

Если при клике на название чата открывается модальное окно:

1. Кликните на название чата, чтобы открыть попап
2. `Ctrl+0` → выбрать `CHAT_NAME_POPUP`
3. Навести курсор на поле ввода в попапе
4. `Ctrl+Shift+P`

#### CHAT_NAME_CONFIRM — Кнопка подтверждения

Если есть кнопка OK/Confirm в попапе:

1. `Ctrl+0` → выбрать `CHAT_NAME_CONFIRM`
2. Навести курсор на кнопку
3. `Ctrl+Shift+P`

## 5. Настройка окна браузера

### Ctrl+Shift+V — Найти и активировать окно

Эта горячая клавиша:

1. Ищет окно браузера с AI Studio
2. Активирует его (выводит на передний план)
3. Устанавливает его как целевое для автоматизации

**Когда использовать**:

- Перед первым запуском генерации
- После переключения между окнами
- Если автоматизация не работает (кликает не туда)

---

## 6. Проверка координат

### Просмотр текущих координат

Нажмите `Ctrl+0` — меню покажет все координаты со статусами:

- `✓ задана` — координата настроена
- `⚠️ не задана` — координата (0, 0), нужно настроить

### Тестовый клик

В v2 будет команда для тестового клика по координатам. В v1 — запустите генерацию и наблюдайте.

## 7. Файл координат

Координаты хранятся в `data/coordinates.json`:

```json
{
	"coordinates": {
		"PROMPT_INPUT": [1234, 567],
		"IMAGE_LOCATION": [890, 123],
		"NEW_CHAT_BUTTON": [456, 789],
		"CHAT_NAME_INPUT": [111, 222],
		"CHAT_NAME_POPUP": [0, 0],
		"CHAT_NAME_CONFIRM": [0, 0],
		"ASPECT_RATIO_SELECTOR": [333, 444],
		"PROMPT_INPUT_AFTER_IMAGE": [0, 0]
	},
	"relative_movements": {
		"TO_SAVE_OPTION": [50, 120]
	}
}
```

**Можно редактировать вручную**, если знаете точные координаты.

## 8. Типичные проблемы

### Координата (0, 0)

**Причина**: Координата не настроена.

**Решение**: Настройте через `Ctrl+0` → `Ctrl+Shift+P`.

### Клик попадает не туда

**Причины**:

- Изменился масштаб страницы
- Окно браузера переместилось
- Изменилось разрешение экрана

**Решение**: Перенастройте все координаты.

### Не открывается контекстное меню

**Причина**: Неправильная координата `IMAGE_LOCATION`.

**Решение**: Перенастройте `IMAGE_LOCATION` точно на центр изображения.

### Не выбирается пункт "Сохранить"

**Причина**: Неправильное относительное движение `TO_SAVE_OPTION`.

**Решение**: Перенастройте:

1. ПКМ по изображению (откроется меню)
2. Наведите на "Сохранить изображение как..."
3. `Ctrl+Shift+P`

---

## 9. Рекомендации

1. **Фиксируйте окно браузера** — не двигайте его после настройки.
2. **Не меняйте масштаб** — Ctrl+0 в браузере для 100%.
3. **Используйте одно разрешение** — не переключайтесь между мониторами.
4. **Проверяйте перед запуском** — `Ctrl+0` покажет статус всех координат.
5. **Бэкапьте файл** — скопируйте `data/coordinates.json` после настройки.
