# Алгоритм режима standard

Пошаговое описание работы стандартного режима генерации изображений.

---

## 1. Общее описание

Стандартный режим (`standard`) предназначен для генерации нескольких изображений на одну карточку. Каждый промпт из файла обрабатывается в отдельном чате AI Studio.

Количество генераций на карточку **определяется из файла промптов** (сколько промптов — столько генераций), а не задаётся настройкой.

---

## 2. Используемые координаты

| Ключ                | Тип                | Описание                                                     | Обязательность |
| ------------------- | ------------------ | ------------------------------------------------------------ | -------------- |
| `PROMPT_INPUT`      | coordinates        | Поле ввода промпта                                           | Обязательно    |
| `IMAGE_LOCATION`    | coordinates        | Место клика на сгенерированное изображение (для сохранения)  | Обязательно    |
| `NEW_CHAT_BUTTON`   | coordinates        | Кнопка создания нового чата                                  | Обязательно    |
| `CHAT_NAME_INPUT`   | coordinates        | Поле ввода названия чата                                     | Обязательно    |
| `CHAT_NAME_POPUP`   | coordinates        | Поле ввода в попапе (если есть)                              | Опционально    |
| `CHAT_NAME_CONFIRM` | coordinates        | Кнопка подтверждения в попапе                                | Опционально    |
| `TO_SAVE_OPTION`    | relative_movements | Смещение к пункту "Сохранить изображение" в контекстном меню | Обязательно    |

---

## 3. Используемые настройки

| Ключ                         | Тип   | Описание                                                        |
| ---------------------------- | ----- | --------------------------------------------------------------- |
| `PROMPTS_FILE`               | str   | Путь к файлу с промптами                                        |
| `START_FROM_CARD`            | int   | С какой карточки начинать                                       |
| `END_CARD`                   | int   | До какой карточки обрабатывать                                  |
| `GENERATION_WAIT`            | float | Время ожидания генерации (секунды)                              |
| `CHECK_IMAGE_GENERATED`      | bool  | Включить проверку готовности изображения                        |
| `IMAGE_CHECK_ATTEMPTS`       | int   | Количество попыток проверки (если CHECK_IMAGE_GENERATED = True) |
| `IMAGE_CHECK_DELAY`          | int   | Секунд между попытками проверки                                 |
| `BACKGROUND_COLOR_TOLERANCE` | int   | Допуск для определения фонового цвета (v1)                      |

---

## 4. Алгоритм работы (верхний уровень)

```
automation_worker(start_card, ..., cards_to_process)
│
├── 1. Загрузить промпты из файла (FileHandler → StandardParser)
│
├── 2. Получить список карточек для обработки:
│      - от START_FROM_CARD до END_CARD
│      - ограничить по CARDS_TO_PROCESS
│
├── 3. Вывести сводку:
│      - "Начинаем с карточки #{start_card}"
│      - "Будет обработано N карточек (M генераций)"
│
├── 4. Цикл по карточкам:
│      │
│      └── process_card(card_number, card_name, prompts_list, ...)
│           │
│           ├── Цикл по промптам карточки:
│           │    └── generate_single_image(prompt, chat_name, filename, ...)
│           │
│           └── Пауза BETWEEN_CARDS между карточками
│
└── 5. Вывести итоговый отчёт:
       - "Обработано карточек: X/Y"
       - "Выполнено генераций: X/Y"
```

## 5. Алгоритм генерации одного изображения

Функция `generate_single_image(prompt, chat_name, filename, check_image_enabled, generation_wait, stop_event)`:

```
1. В файл: [GEN] "Генерация: {chat_name}"

2. Создать новый чат:
   - Клик по NEW_CHAT_BUTTON
   - Пауза NEW_CHAT_WAIT

3. Ввести промпт:
   - Клик по PROMPT_INPUT
   - Пауза BETWEEN_CLICKS
   - Вставить текст промпта через буфер обмена (Ctrl+V)
   - Пауза AFTER_PASTE

4. Переименовать чат:
   - Клик по CHAT_NAME_INPUT
   - Пауза BETWEEN_CLICKS
   - Вставить название чата через буфер обмена
   - Enter для подтверждения
   - Пауза CHAT_RENAME_WAIT

5. Вернуться к полю ввода промпта:
   - Клик по PROMPT_INPUT
   - Пауза BETWEEN_CLICKS

6. Запустить генерацию:
   - Нажать Ctrl+Enter
   - Пауза BETWEEN_CLICKS

7. Ожидание генерации:
   - Ждать GENERATION_WAIT секунд (с проверкой stop_event каждую секунду)

8. Проверка изображения (если CHECK_IMAGE_GENERATED = True):
   - Цикл до IMAGE_CHECK_ATTEMPTS попыток:
     - Проверить цвет пикселя в IMAGE_LOCATION
     - Если не фоновый цвет → изображение готово, выход из цикла
     - Иначе → ждать IMAGE_CHECK_DELAY секунд и повторить
   - Если все попытки исчерпаны → продолжить сохранение

9. Сохранить изображение:
   - Скопировать имя файла в буфер обмена
   - Правый клик по IMAGE_LOCATION (открыть контекстное меню)
   - Пауза CONTEXT_MENU_WAIT
   - Переместить курсор на TO_SAVE_OPTION (относительное движение)
   - Пауза BETWEEN_CLICKS
   - Клик (выбрать пункт "Сохранить изображение")
   - Пауза SAVE_DIALOG_WAIT
   - Вставить имя файла (Ctrl+V)
   - Пауза BETWEEN_CLICKS
   - Enter (подтвердить сохранение)
   - Пауза AFTER_SAVE
   - Восстановить буфер обмена

10. В файл: [OK] "Файл сохранён: {filename}"
```

---

## 6. Формат имени чата

```
Карточка {card_number} - генерация {gen_num}
```

Примеры:

- `Карточка 1 - генерация 1`
- `Карточка 5 - генерация 3`

---

## 7. Формат имени файла

Единый формат для всех режимов:

```
Карточка_{номер}_{сторона_карточки}_промпт_{номер_промпта}.png
```

Для режима **standard** сторона по умолчанию — **лицевая** (одна сторона карточки).

**Примеры**:

- `Карточка_1_лицевая_промпт_1.png`
- `Карточка_1_лицевая_промпт_2.png`
- `Карточка_5_лицевая_промпт_1.png`

---

## 8. Логирование

Все детальные логи пишутся **в файл** в `logs/` (при запуске создаётся новый файл с именем по дате и времени до секунды). В консоль — только основные шаги (см. LOGGING.md). Эмодзи не используются, только теги капсом.

| Тег       | Пример (в файле)                          | Когда               |
| --------- | ----------------------------------------- | ------------------- |
| `[CARD]`  | `[CARD] Карточка 1`                        | Начало карточки     |
| `[GEN]`   | `[GEN] Генерация: Карточка 1 - ...`       | Начало генерации    |
| `[OK]`    | `[OK] Файл сохранён: filename.png`        | Успешное сохранение |
| `[ERROR]` | `[ERROR] Ошибка при сохранении файла: ...`| Ошибка              |
| `[SUMMARY]` | `[SUMMARY] Карточек: 10, генераций: 24` | Итоги работы        |

---

## 9. Обработка ошибок

- Если координата не задана (0, 0) → функция возвращает False, генерация прерывается.
- Если файл промптов не найден или пуст → воркер завершается с сообщением.
- Если промпт пустой → генерация пропускается с предупреждением.
- Все исключения ловятся и логируются; работа продолжается со следующей генерацией/карточкой.

---

## 10. Паузы (задержки)

Задержки берутся из `config/coordinates.py → DELAYS`:

| Ключ                  | Значение | Назначение                         |
| --------------------- | -------- | ---------------------------------- |
| `BETWEEN_CLICKS`      | 0.5 сек  | Между кликами                      |
| `AFTER_PASTE`         | 1.0 сек  | После вставки промпта              |
| `GENERATION_WAIT`     | 20.0 сек | Ожидание генерации (настраивается) |
| `IMAGE_OPEN_WAIT`     | 1.0 сек  | Ожидание открытия изображения      |
| `CONTEXT_MENU_WAIT`   | 0.5 сек  | Появление контекстного меню        |
| `SAVE_DIALOG_WAIT`    | 1.0 сек  | Открытие диалога сохранения        |
| `AFTER_SAVE`          | 2.0 сек  | После сохранения файла             |
| `NEW_CHAT_WAIT`       | 2.0 сек  | Создание нового чата               |
| `CHAT_RENAME_WAIT`    | 1.0 сек  | Переименование чата                |
| `BETWEEN_GENERATIONS` | 1.0 сек  | Между генерациями одной карточки   |
| `BETWEEN_CARDS`       | 2.0 сек  | Между карточками                   |
