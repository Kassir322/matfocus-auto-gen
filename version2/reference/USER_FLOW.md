# Сценарий пользователя

Актуальный пользовательский сценарий для текущего v2 runtime. Основной путь работы сейчас — **hotkey-first** через `python main.py`. Консольное меню существует как вспомогательный модуль, но не является главным UX приложения.

---

## 1. Требования

- Windows 10/11
- Python 3.9+
- Установленные зависимости из `requirements.txt`
- Для browser-ветки: Chrome / Edge / Firefox, открытый AI Studio
- Для API-ветки: API ключ Google AI Studio

---

## 2. Запуск

Основной запуск:

```bash
python main.py
```

После старта программа:

- печатает актуальную шпаргалку по хоткеям;
- регистрирует горячие клавиши;
- остаётся работать в фоне как управляющий процесс.

Отдельный вспомогательный сценарий:

```bash
python -m ui.console_menu
```

Он подходит для ручной проверки конфигурации, но основной реальный сценарий v2 всё равно построен вокруг hotkeys.

---

## 3. Настройка browser-режима

### 3.1. Подготовить окно

1. Откройте AI Studio в браузере.
2. Нажмите `Ctrl+Shift+V` для быстрой настройки окна.
3. Если окно не найдено, запуск browser-генерации сам попробует создать и настроить новое окно.

### 3.2. Настроить координаты

1. Нажмите `Ctrl+0`.
2. Выберите нужную координату.
3. Наведите курсор на элемент UI.
4. Нажмите `Ctrl+Shift+P`.

Минимально обязательные координаты зависят от режима:

- `standard`: `PROMPT_INPUT`, `IMAGE_LOCATION`, `NEW_CHAT_BUTTON`, `CHAT_NAME_INPUT`, `TO_SAVE_OPTION`
- `multiformat`: то же + `ASPECT_RATIO_SELECTOR`
- `multiformat_with_refs`: то же + `PROMPT_INPUT_AFTER_IMAGE`

### 3.3. Настроить параметры

Через хоткеи:

- `Ctrl+1` — `START_FROM_CARD`
- `Ctrl+3` — `GENERATION_WAIT`
- `Ctrl+4` — `CHECK_IMAGE_GENERATED`
- `Ctrl+5` — показать текущие настройки и план
- `Ctrl+6` — `END_CARD`
- `Ctrl+7` — выбрать `browser/api` и режим
- `Ctrl+8` — `IMAGE_WAIT_INTERVAL`
- `Ctrl+9` — `FACE_ASPECT_RATIO` / `BACK_ASPECT_RATIO`

---

## 4. Настройка API-режима

1. Нажмите `Ctrl+7`.
2. Выберите метод `api`.
3. Настройте модель, размер изображения и API ключ.
4. Проверьте текущие настройки через `Ctrl+5`.
5. Запускайте API-генерацию через `Ctrl+Shift+A`.

Особенности API-ветки:

- координаты и окно браузера не требуются;
- во время активного API-воркера foreground-хоткеи блокируются;
- `Esc` API-воркер не останавливает;
- для завершения используйте `Ctrl+Esc` или закройте консоль.

---

## 5. Файл промптов

Технически `ui.console_menu` умеет выбирать файл из `data/`, но в реальном рабочем сценарии надёжнее считать источником истины `data/settings.json`, ключ `PROMPTS_FILE`.

Практический путь:

1. Подготовить файл промптов.
2. Положить его в `data/` или указать абсолютный/относительный путь.
3. Убедиться, что `PROMPTS_FILE` в `data/settings.json` указывает на нужный файл.

Форматы:

- `standard`: `Карточка N - Промпт M: текст`
- `multiformat`: `Карточка N лицо|оборот Название - Промпт M: текст`
- `multiformat_with_refs`: тот же формат, что и `multiformat`

---

## 6. Референсы для `multiformat_with_refs`

Референсы сейчас являются **необязательными**.

Поддерживаемый рабочий сценарий:

- часть сторон карточек идёт с референсами;
- часть — без них;
- при отсутствии референса генерация продолжается как обычный `multiformat`, с предупреждением.

Поддерживаемые имена файлов:

- упрощённый формат: `{card_number}_{side}.png/.jpg`
- полный формат: `{side}_{card_number}_{safe_card_name}.png/.jpg`

Папки:

- `data/images/лицо/`
- `data/images/оборот/`

---

## 7. Запуск генерации

### Browser

1. Настройте окно и координаты.
2. Выберите метод `browser` через `Ctrl+7`.
3. Проверьте настройки и план через `Ctrl+5`.
4. Нажмите `Ctrl+Shift+S`.

### API

1. Выберите метод `api` через `Ctrl+7`.
2. Проверьте API ключ и модели.
3. Нажмите `Ctrl+Shift+A`.

---

## 8. Что видно в консоли

Консоль показывает только основные шаги:

- старт генерации;
- прогресс;
- завершение;
- сообщения об остановке и блокирующих ошибках.

Актуальный формат прогресса в browser-режимах:

```text
Генерация X/Y из Z
```

Где:

- `X` — число успешных сохранений;
- `Y` — число уже выполненных попыток;
- `Z` — общее число запланированных изображений/генераций.

---

## 9. Остановка

### Browser-воркер

- `Esc` — жёсткая остановка подпроцесса
- `Ctrl+Esc` — завершение всей консоли

### API-воркер

- `Esc` не используется для остановки
- `Ctrl+Esc` или закрытие консоли — рабочий способ завершения

---

## 10. Где смотреть состояние

- Настройки: `data/settings.json`
- Координаты: `data/coordinates.json`
- Логи: `logs/`
- Генерируемые файлы browser-ветки: стандартный сценарий браузера/диалога сохранения
- Генерируемые файлы API-ветки: в выходной папке сессии API
