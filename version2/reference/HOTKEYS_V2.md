## Hotkeys v2 (полный список)

Цель: сохранить привычное управление из v1, но с новой логикой v2 (подпроцесс + жёсткая остановка).

---

### Базовые хоткеи управления

- **Ctrl+Shift+P** — получить координаты курсора.
  - Если включён режим захвата координаты (после Ctrl+0) — сохранить координату в `coordinates.json`.
  - Иначе — просто вывести X/Y в консоль.

- **Ctrl+0** — меню настройки координат.
  - Показать список ключей из `coordinates` и `relative_movements` с номерами.
  - Пользователь вводит номер → включается режим захвата для выбранного ключа.
  - Далее пользователь наводит мышь на элемент UI и нажимает Ctrl+Shift+P.

- **Ctrl+Shift+V** — настройка рабочего окна браузера (быстрая).
  - Найти окно браузера → выставить размер/позицию.

- **Ctrl+Shift+S** — старт генерации.
  - Запуск выбранного `CURRENT_SITE` + `CURRENT_MODE` в отдельном процессе.

- **Esc** — экстренная остановка.
  - Если подпроцесс генерации запущен → `terminate()` + `join(timeout)`.
  - (Опционально) второй вариант поведения: после остановки подпроцесса — выход из программы.

---

### Настройки (через хоткеи)

Набор можно сохранить как в v1, но привязать к новым ключам из `SETTINGS_V2.md`.

- **Ctrl+1** — настроить `START_FROM_CARD`.
- **Ctrl+6** — настроить `END_CARD`.
- **Ctrl+3** — настроить `GENERATION_WAIT`.
- **Ctrl+8** — настроить `IMAGE_WAIT_INTERVAL`.
- **Ctrl+4** — переключить `CHECK_IMAGE_GENERATED`.
- **Ctrl+9** — настроить `FACE_ASPECT_RATIO` и `BACK_ASPECT_RATIO`.
- **Ctrl+7** — выбрать режим генерации для текущего сайта (или открыть меню выбора режимов).
- **Ctrl+5** — показать текущие настройки + “план” (сколько карточек/изображений будет).

---

### Примечания

- В v2 **нет** `Ctrl+Shift+Q` для остановки: остановка только по **Esc**.
- В v2 нет настройки `GENERATIONS_PER_CARD`.
- Любые генерации идут в подпроцессе: основной процесс всегда остаётся живым и может убить воркер.
