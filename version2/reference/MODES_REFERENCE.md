# Справка по режимам генерации (для промптов)

Краткое описание трёх режимов: что делают, формат входа, структура задачи, ключевые шаги. Прикладывать к промпту при написании/правке кода режимов. Подробно — ALGO_*.md и INTERFACE_aistudio_modes.md.

---

## 1. standard

**Назначение:** несколько изображений на одну карточку; каждый промпт — отдельный чат.

**Вход (файл промптов):**
```
Карточка N - Промпт M: текст промпта
```
Одна карточка может иметь несколько строк (M = 1, 2, …).

**Task (одна генерация):** `card_number`, `generation_number`, `prompt_text`. Имя чата: `Карточка {N} - генерация {M}`. Имя файла: `Карточка_{N}_лицевая_промпт_{M}.png`.

**Ключевые шаги на одну генерацию:** новый чат → клик PROMPT_INPUT → вставка промпта (Ctrl+V) → переименование чата → Ctrl+Enter → ожидание (по LOGGING/IMAGE_READY) → ПКМ по IMAGE_LOCATION → TO_SAVE_OPTION → вставка имени файла → Enter. Координаты: PROMPT_INPUT, IMAGE_LOCATION, NEW_CHAT_BUTTON, CHAT_NAME_INPUT, TO_SAVE_OPTION.

---

## 2. multiformat

**Назначение:** пары изображений — лицо и оборот карточки с разными соотношениями сторон (FACE_ASPECT_RATIO, BACK_ASPECT_RATIO).

**Вход (файл промптов):**
```
Карточка N лицо Название - Промпт M: текст
Карточка N оборот Название - Промпт M: текст
```
Парсер даёт пары; неполные пары — WARN, можно пропускать сторону.

**Task (одна сторона):** `card_number`, `card_name`, `pair_number`, `side` ("лицо" | "оборот"), `prompt_text`, `aspect_ratio`. Имя файла: `Карточка_{N}_{side}_промпт_{M}.png` (без названия карточки в имени файла).

**Ключевые шаги на одну сторону:** как standard, плюс после ввода промпта — клик ASPECT_RATIO_SELECTOR, ввод aspect_ratio, Enter. Порядок: для каждой пары сначала лицо, потом оборот. Координаты: те же + ASPECT_RATIO_SELECTOR.

---

## 3. multiformat_with_refs

**Назначение:** как multiformat, но перед промптом в чат вставляется референс из `data/images/лицо/` и `data/images/оборот/`. Имя референса: `{side}_{card_number}_{safe_card_name}.png` (или .jpg).

**Вход:** тот же формат файла промптов, что в multiformat. Референсы проверяются перед стартом; при отсутствии — WARN или пропуск (по решению).

**Task:** как в multiformat; путь к референсу вычисляется по side, card_number, card_name (функция get_reference_path).

**Ключевые шаги на одну сторону:** новый чат → вставка изображения референса в чат (буфер обмена) → клик PROMPT_INPUT_AFTER_IMAGE → вставка промпта → переименование чата → выбор aspect_ratio → Ctrl+Enter → ожидание → сохранение. Координаты: те же что multiformat + PROMPT_INPUT_AFTER_IMAGE.

---

## Общее для всех режимов

- **Имя файла изображения:** `Карточка_{номер}_{сторона}_промпт_{номер_промпта}.png`. Для standard сторона = «лицевая».
- **Логирование:** в файл (новый при запуске, имя с датой до секунды), теги капсом ([PLAN], [CARD], [GEN], [OK], [WARN], [SUMMARY] и т.д.), без эмодзи; в консоль — только основные шаги.
- **Координаты:** два словаря — `coordinates` и `relative_movements`; в режимы передавать оба отдельно.
- **Остановка:** только жёсткий стоп (Esc → terminate воркера); проверок флагов в воркере нет.
