# API Integration — Генерация изображений через Gemini API

Документация по интеграции Gemini API в проект v2 для генерации изображений без браузера.

---

## Обзор

Начиная с версии v2, программа поддерживает **два метода генерации**:

1. **Browser** (браузерная автоматизация) — существующий метод через pyautogui, координаты и браузер
2. **API** (Gemini API) — новый метод через Google Gemini API (модель `gemini-2.5-flash-image`)

Пользователь может выбрать метод в настройках через горячую клавишу `Ctrl+7`.

---

## Преимущества API-режима

✅ **Не требуется настройка координат** (нет Ctrl+0, Ctrl+Shift+P)  
✅ **Не требуется настройка окна браузера** (нет Ctrl+Shift+V)  
✅ **Быстрее**: нет задержек UI, кликов, ожиданий готовности изображения  
✅ **Стабильнее**: нет зависимости от разрешения экрана, масштабирования браузера  
✅ **Меньше ресурсов**: не требуется открытый браузер

---

## Ограничения API-режима

❌ **Требуется API ключ** (возможны лимиты бесплатного доступа)  
❌ **Нет истории чатов в AI Studio** (изображения генерируются напрямую, без UI)  
❌ **Режим с референсами не поддерживается** (в первой версии интеграции)

## Быстрый старт

### 1. Получение API ключа

1. Откройте https://aistudio.google.com/apikey
2. Войдите в аккаунт Google
3. Нажмите "Get API key" или "Create API key"
4. Скопируйте ключ (формат: `AIza...`, ~39 символов)

### 2. Настройка программы

Запустите программу:

```bash
python main.py
```

Нажмите `Ctrl+7`:

1. Выберите метод генерации — **2. api**
2. Введите ваш API ключ (или обновите существующий)
3. Выберите режим генерации (**standard** или **multiformat**)

Выберите файл промптов (или положите файл в `data/`) и запустите генерацию через `Ctrl+Shift+S`

### 3. Генерация изображений

При запуске генерации программа:

- Проверит валидность API ключа
- Инициализирует клиент Gemini API
- Для каждого промпта:
  - Отправит запрос в API
  - Получит изображение в формате PNG
  - Сохранит файл с именем по NAMING_RULES
  - Запишет логи в `logs/auto-gen_YYYY-MM-DD_HH-MM-SS.log`

## Технические детали

### Поддерживаемые режимы

| Режим                      | API поддержка | Браузер поддержка |
| -------------------------- | ------------- | ----------------- |
| `standard`                 | ✅ Да         | ✅ Да             |
| `multiformat`              | ✅ Да         | ✅ Да             |
| `multiformat_with_refs`    | ❌ Нет        | ✅ Да             |

### Модели Gemini

#### gemini-2.5-flash-image (по умолчанию)

- **Скорость**: быстрая
- **Качество**: хорошее
- **Разрешение**: фиксированное (~1K)
- **Рекомендуется для**: массовой генерации, быстрых задач

#### gemini-3-pro-image-preview

- **Скорость**: медленнее
- **Качество**: очень высокое
- **Разрешение**: настраиваемое (1K, 2K, 4K)
- **Рекомендуется для**: финальных изображений, высокое качество

**Как изменить модель:**

В `data/settings.json` измените:

```json
{
  "API_MODEL": "gemini-3-pro-image-preview",
  "API_IMAGE_SIZE": "2K"
}
```

### Aspect Ratio

API режим использует те же настройки `FACE_ASPECT_RATIO` и `BACK_ASPECT_RATIO`, что и браузерный режим.

**Поддерживаемые форматы:**

- `"1:1"` — квадрат
- `"4:3"` — стандартный альбомный
- `"3:4"` — стандартный портретный
- `"16:9"` — широкоформатный альбомный
- `"9:16"` — широкоформатный портретный
- `"3:2"`, `"2:3"`, `"4:5"`, `"5:4"`, `"21:9"` — другие форматы

**Настройка:**

Через горячую клавишу `Ctrl+9` или вручную в `data/settings.json`:

```json
{
  "FACE_ASPECT_RATIO": "4:3",
  "BACK_ASPECT_RATIO": "3:2"
}
```

### Rate Limits и задержки

API имеет ограничения на количество запросов в минуту. Программа автоматически добавляет задержку **1 секунда** между запросами для соблюдения лимитов.

**Обработка ошибок 429 (Too Many Requests):**

В текущей версии ошибка логируется, генерация пропускается. В будущих версиях планируется автоматический retry с exponential backoff.

### Таймауты

По умолчанию таймаут API запроса — **60 секунд**. Настраивается через:

```json
{
  "API_TIMEOUT": 60.0
}
```

### Логирование

API режим использует те же теги логирования, что и браузерный:

- `[PLAN]` — начало генерации, параметры
- `[CARD]` — обработка карточки
- `[PAIR]` — обработка пары промптов (для multiformat)
- `[GEN]` — начало генерации изображения
- `[API_REQUEST]` — отправка запроса в API (новый тег)
- `[API_RESPONSE]` — получение ответа (новый тег)
- `[OK]` — успешное сохранение
- `[ERROR]` — ошибка генерации/сохранения
- `[SUMMARY]` — итоги

**Пример лога:**

```
[PLAN] Режим: standard (API). Карточек: 3, генераций: 9
[PLAN] Файл промптов: data/prompts.txt
[PLAN] API модель: gemini-2.5-flash-image
[CARD] Карточка 1
[GEN] Генерация через API: карточка 1 генерация 1
[API_REQUEST] model=gemini-2.5-flash-image, prompt_length=142
[API_RESPONSE] Получено изображение, размер: 245612 байт
[OK] Файл сохранён: Карточка_1_лицевая_промпт_1.png
...
[SUMMARY] Карточек: 3, генераций: 9/9
```

## Архитектура API-режимов

### Модули

```
utils/
  api_client.py           # Клиент Gemini API
  prompt_parsers.py       # Парсеры промптов (общие для browser/api)
  generation_runner.py    # Воркеры для API и browser
sites/aistudio/
  mode_standard_api.py    # Standard режим через API
  mode_multiformat_api.py # Multiformat режим через API
```

### Поток выполнения

```
main.py: on_start_generation()
  ↓
settings["GENERATION_METHOD"] == "api"?
  ↓ да
can_start_generation_api() — проверка API ключа, файла промптов
  ↓ ok
run_standard_worker_api() или run_multiformat_worker_api()
  ↓
mode_standard_api.run_mode() или mode_multiformat_api.run_mode()
  ↓
для каждой задачи:
  ↓
api_client.generate_image() — запрос в API
  ↓
api_client.save_image_bytes() — сохранение PNG
  ↓
логирование [OK] или [ERROR]
```

### API клиент (utils/api_client.py)

**Функции:**

- `init_client(api_key: str) -> genai.Client` — инициализация клиента
- `generate_image(client, prompt, model, aspect_ratio, image_size, timeout) -> bytes | None` — генерация изображения
- `save_image_bytes(image_bytes: bytes, file_path: str) -> bool` — сохранение PNG
- `check_api_key_format(api_key: str) -> tuple[bool, str]` — валидация ключа

**Зависимости:**

```bash
pip install google-genai
```

## Устранение неполадок

### Ошибка: "google-genai не установлена"

**Решение:**

```bash
pip install google-genai
```

### Ошибка: "API_KEY не задан"

**Решение:**

1. Запустите программу: `python main.py`
2. Нажмите `Ctrl+7`
3. Выберите метод `api` и введите ключ с https://aistudio.google.com/apikey

### Ошибка: "API ключ должен начинаться с 'AIza'"

**Причина:** неверный формат ключа.

**Решение:** проверьте, что скопировали ключ полностью (без пробелов, ~39 символов).

### Ошибка: "API вернул пустой результат"

**Возможные причины:**

- Сетевая ошибка (проверьте интернет-соединение)
- Превышен rate limit (программа автоматически ждёт 1 сек между запросами)
- Промпт на неподдерживаемом языке (API лучше работает с английским)
- Недостаточно квоты на API ключе (проверьте лимиты в AI Studio)

**Решение:** проверьте логи в `logs/auto-gen_YYYY-MM-DD_HH-MM-SS.log` для деталей ошибки.

### Режим с референсами не работает через API

**Причина:** `multiformat_with_refs` пока не поддерживается в API режиме.

**Решение:**

- Используйте браузерный режим (`GENERATION_METHOD = "browser"`)
- Или выберите режим `standard` или `multiformat` для API

## Сравнение Browser vs API

| Параметр                | Browser (pyautogui)      | API (Gemini)               |
| ----------------------- | ------------------------ | -------------------------- |
| **Скорость**            | Медленно (клики, задержки) | Быстро (сетевые запросы)   |
| **Настройка**           | Координаты, окно браузера | Только API ключ            |
| **Стабильность**        | Зависит от UI            | Стабильно                  |
| **История чатов**       | ✅ Сохраняется в AI Studio | ❌ Нет истории              |
| **Референсы**           | ✅ Поддерживается         | ❌ Пока не реализовано      |
| **Ресурсы**             | Браузер + Python         | Только Python              |
| **Aspect ratio**        | ✅ Поддерживается         | ✅ Поддерживается          |
| **Multiformat**         | ✅ Поддерживается         | ✅ Поддерживается          |

## FAQ

**Q: Какой метод выбрать?**

A: Если вам не нужна история чатов в AI Studio и вы хотите максимальную скорость — выбирайте API. Если нужна история или режим с референсами — используйте Browser.

**Q: Можно ли переключаться между методами?**

A: Да, в любой момент через горячую клавишу `Ctrl+7`.

**Q: API бесплатный?**

A: Google AI Studio предоставляет бесплатную квоту для Gemini API. Проверьте актуальные лимиты на https://ai.google.dev/pricing

**Q: Промпты на русском работают?**

A: API официально поддерживает только английский, но может работать и с русским. Качество результата может варьироваться.

**Q: Можно ли использовать несколько API ключей для увеличения квоты?**

A: В текущей версии программа использует один ключ из настроек. Ротация ключей не реализована.
