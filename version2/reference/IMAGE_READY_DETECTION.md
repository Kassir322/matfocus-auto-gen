# Проверка готовности изображения

Алгоритм определения момента, когда изображение сгенерировано и готово к сохранению.

---

## 1. Проблема

При генерации изображения в AI Studio:

1. Пользователь отправляет промпт
2. Появляется индикатор загрузки
3. Через N секунд появляется изображение

**Проблема**: Время генерации непостоянно (10-60+ секунд).

**Решения**:

- Ждать фиксированное время (может быть слишком долго или недостаточно)
- Анализировать область экрана и определять, появилось ли изображение

---

## 2. Алгоритм v2

### 2.1. Основная идея

1. Захватить скриншот области, где должно появиться изображение
2. Проверить, отличается ли область от "пустой" (фон без изображения)
3. Если отличается значительно → изображение готово
4. Если не отличается → ждать и повторить

### 2.2. Псевдокод

```python
def wait_until_image_ready(image_location, timeout, interval, box_size, diff_threshold):
    """
    Ждёт появления изображения или истечения таймаута.

    Аргументы:
        image_location: (x, y) — центр области проверки
        timeout: максимальное время ожидания (секунды)
        interval: интервал между проверками (секунды)
        box_size: размер области проверки (пиксели)
        diff_threshold: порог отличия (0.0-1.0)

    Возвращает:
        True — изображение появилось
        False — таймаут истёк
    """
    # Захватить "пустой" скриншот (до генерации)
    baseline = grab_result_area(image_location, box_size)

    start_time = time.time()

    while time.time() - start_time < timeout:
        time.sleep(interval)

        # Захватить текущий скриншот
        current = grab_result_area(image_location, box_size)

        # Сравнить с baseline
        diff_score = compute_difference_score(baseline, current)

        if diff_score > diff_threshold:
            return True  # Изображение появилось

    return False  # Таймаут
```

## 3. Захват области экрана

```python
import pyautogui
from PIL import Image

def grab_result_area(center, box_size):
    """
    Захватывает область экрана вокруг указанной точки.

    Аргументы:
        center: (x, y) — центр области
        box_size: размер стороны квадрата (пиксели)

    Возвращает:
        PIL.Image — скриншот области
    """
    x, y = center
    half = box_size // 2

    # Координаты области
    left = x - half
    top = y - half

    # Захват скриншота
    screenshot = pyautogui.screenshot(region=(left, top, box_size, box_size))

    return screenshot
```

## 4. Вычисление различия

### 4.1. Метод: Среднее отклонение пикселей

```python
import numpy as np

def compute_difference_score(image1, image2):
    """
    Вычисляет степень различия двух изображений.

    Возвращает:
        float: 0.0 (идентичны) — 1.0 (полностью разные)
    """
    # Конвертируем в массивы numpy
    arr1 = np.array(image1, dtype=np.float32)
    arr2 = np.array(image2, dtype=np.float32)

    # Вычисляем среднее абсолютное отклонение
    diff = np.abs(arr1 - arr2)
    mean_diff = np.mean(diff)

    # Нормализуем к диапазону 0-1
    # (максимальное отклонение для RGB = 255)
    score = mean_diff / 255.0

    return score
```

### 4.2. Альтернативный метод: Процент изменённых пикселей

```python
def compute_changed_pixels_ratio(image1, image2, pixel_threshold=30):
    """
    Вычисляет долю пикселей, которые изменились.

    Аргументы:
        pixel_threshold: минимальное изменение для "изменённого" пикселя

    Возвращает:
        float: 0.0 — 1.0 (доля изменённых пикселей)
    """
    arr1 = np.array(image1, dtype=np.float32)
    arr2 = np.array(image2, dtype=np.float32)

    # Считаем разницу по каждому каналу
    diff = np.abs(arr1 - arr2)

    # Пиксель считается изменённым, если любой канал изменился
    max_diff_per_pixel = np.max(diff, axis=2)
    changed_pixels = max_diff_per_pixel > pixel_threshold

    ratio = np.mean(changed_pixels)

    return ratio
```

## 5. Настраиваемые параметры

| Параметр                | Описание                                  | Значение по умолчанию |
| ----------------------- | ----------------------------------------- | --------------------- |
| `GENERATION_WAIT`       | Максимальное время ожидания (таймаут)     | 60.0 сек              |
| `IMAGE_WAIT_INTERVAL`   | Интервал между проверками                 | 2.0 сек               |
| `IMAGE_CHECK_BOX_SIZE`  | Размер области проверки                   | 100 пикселей          |
| `IMAGE_CHECK_THRESHOLD` | Порог различия для определения готовности | 0.1 (10%)             |

## 8. Рекомендации по настройке

### 8.1. IMAGE_CHECK_BOX_SIZE

- **Слишком маленький** (< 50px): может не захватить изменение
- **Слишком большой** (> 200px): может захватить лишние элементы
- **Рекомендуется**: 80-120 пикселей

### 8.2. IMAGE_CHECK_THRESHOLD

- **Слишком низкий** (< 0.05): ложные срабатывания от мерцания
- **Слишком высокий** (> 0.3): может не сработать для тёмных изображений
- **Рекомендуется**: 0.08-0.15

### 8.3. IMAGE_WAIT_INTERVAL

- **Слишком частый** (< 1 сек): нагрузка на CPU
- **Слишком редкий** (> 5 сек): задержка после готовности
- **Рекомендуется**: 2-3 секунды

---

## 9. Возможные проблемы

### 9.1. Ложные срабатывания

**Причина**: Мерцание курсора или анимация загрузки.

**Решение**:

- Увеличить `IMAGE_CHECK_THRESHOLD`
- Добавить проверку нескольких последовательных срабатываний

### 9.2. Пропуск готовности

**Причина**: Изображение слишком похоже на фон (тёмное/светлое).

**Решение**:

- Уменьшить `IMAGE_CHECK_THRESHOLD`
- Использовать метод "процент изменённых пикселей"

### 9.3. Область проверки не там

**Причина**: Неправильно задана координата `IMAGE_LOCATION`.

**Решение**: Перенастроить координату точно на центр области изображения.

---

## 10. Fallback: Фиксированное ожидание

Если проверка работает нестабильно:

1. Установить `CHECK_IMAGE_GENERATED = False`
2. Установить `GENERATION_WAIT` с запасом (например, 45-60 сек)
3. Программа будет просто ждать это время

```python
# В settings.json
{
  "CHECK_IMAGE_GENERATED": false,
  "GENERATION_WAIT": 45.0
}
```
