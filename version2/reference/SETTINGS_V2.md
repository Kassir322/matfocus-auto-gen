# Настройки v2 — описание

Спецификация настроек для AI Studio Automation v2. Логирование всегда включено; настройки SAVE_FOLDER и LOG_ENABLED не добавляем.

---

## 1. Выбор сайта и режима

| Ключ           | Тип | Описание                                                   | Как задаётся                                                                        |
| -------------- | --- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `CURRENT_SITE` | str | Идентификатор сайта (например, `aistudio`)                 | Пункт меню «Выбрать сайт» — нумерованный список сайтов                              |
| `CURRENT_MODE` | str | Идентификатор режима (например, `standard`, `multiformat`) | Пункт меню «Выбрать режим сайта» — нумерованный список режимов для выбранного сайта |

---

## 2. Файл промптов

| Ключ           | Тип | Описание                                                             | Как задаётся                                                                |
| -------------- | --- | -------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `PROMPTS_FILE` | str | Путь к файлу с промптами (относительно корня проекта или абсолютный) | Пункт меню «Выбрать файл промптов» — см. раздел «Выбор файла промптов» ниже |

### Выбор файла промптов (select_prompts_file)

- Программа сканирует содержимое директории `data` (только файлы, папки не показываются).
- Выводит список файлов нумерованным списком (1, 2, 3, …).
- Пользователь вводит номер нужного файла.
- В `settings["PROMPTS_FILE"]` записывается путь к выбранному файлу (например, `data/all_card_prompts.txt`).
- Если в `data` нет файлов — вывести сообщение и не менять `PROMPTS_FILE`.

---

## 3. Диапазон карточек

Количество генераций на карточку не задаётся отдельно: программа получает данные из файла промптов и по нему определяет, сколько промптов (и генераций) у каждой карточки.

| Ключ               | Тип | Описание                                                                    | Как задаётся                                                                               |
| ------------------ | --- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `START_FROM_CARD`  | int | Номер карточки, с которой начинать обработку (≥ 1)                          | Пункт меню или отдельная настройка: ввод числа                                             |
| `END_CARD`         | int | Номер карточки, до которой обрабатывать (включительно, ≥ START_FROM_CARD)   | Пункт меню или отдельная настройка: ввод числа                                             |
| `CARDS_TO_PROCESS` | int | Сколько карточек обрабатывать (вычисляется: END_CARD − START_FROM_CARD + 1) | Вычисляется при изменении START_FROM_CARD или END_CARD, не вводится пользователем напрямую |

---

## 4. Ожидание генерации и проверка изображения

| Ключ                    | Тип   | Описание                                                                                                                                                                | Как задаётся                                   |
| ----------------------- | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `GENERATION_WAIT`       | float | Максимальное время ожидания генерации (секунды). Используется как таймаут в `wait_until_image_ready`. Диапазон, например: 10–120                                        | Пункт меню или отдельная настройка: ввод числа |
| `IMAGE_WAIT_INTERVAL`   | float | Интервал между проверками «сгенерировано ли изображение» (секунды). Раньше называлось IMAGE_WAIT_TIME. Диапазон, например: 1–60                                         | Пункт меню или отдельная настройка: ввод числа |
| `CHECK_IMAGE_GENERATED` | bool  | Включить проверку готовности изображения по скриншоту и прекращать ожидание, как только изображение появилось. Если выключено — ждём только до таймаута GENERATION_WAIT | Переключатель (вкл/выкл) в меню или настройках |
| `diff_threshold`        | float | Порог отличия скриншота для признания «изображение готово» (опционально в настройках; может быть константой в коде)                                                     | По соглашению реализации                       |
| `box_size`              | tuple | Размер области скриншота (width, height) вокруг IMAGE_LOCATION (опционально в настройках)                                                                               | По соглашению реализации                       |

Пояснение: настройка `CHECK_IMAGE_GENERATED` в v2 сохраняем. Она включает проверку по скриншоту и ранний выход из ожидания. Если анализ работает плохо, пользователь может выключить её и тогда программа будет просто ждать фиксированное время `GENERATION_WAIT`.

## 5. Соотношения сторон (мультиформатный режим)

| Ключ                | Тип | Описание                                                                                                                                                                                                    | Как задаётся                                                                                                                                                                                                                                                        |
| ------------------- | --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FACE_ASPECT_RATIO` | str | Соотношение сторон для лицевой стороны (например, `4:3`, `16:9`). Обязательно задаётся пользователем                                                                                                        | Пункт меню «Настроить соотношения сторон»: ввод строки в формате X:Y                                                                                                                                                                                                |
| `BACK_ASPECT_RATIO` | str | Соотношение сторон для оборотной стороны (например, `3:2`). Используется только в режимах, где у карточки две стороны с изображениями (лицо + оборот). В режимах без двух сторон карточки можно не задавать | Пункт меню «Настроить соотношения сторон»: ввод строки в формате X:Y либо пустая строка — «не использовать». В интерфейсе явно указать: «BACK_ASPECT_RATIO только для генераций с двумя сторонами карточки (лицо и оборот); в остальных режимах можно не указывать» |

Оба параметра должны быть доступны для настройки; при этом пользователю даётся возможность не указывать `BACK_ASPECT_RATIO`, с пояснением, что он нужен только для режимов с двумя сторонами карточки.

## 6. Координаты интерфейса

Координаты и относительные движения хранятся отдельно от `settings` (например, в `data/coordinates.json`). Способ настройки в v2 — тот же, что в текущей программе.

### 6.1. Текущий способ настройки координат (сохраняем в v2)

1. Пользователь нажимает горячую клавишу «Меню настройки координат» (в текущей программе — Ctrl+0).
2. Открывается меню настройки координат:
   - выводится список всех координат и относительных движений с номерами и короткими описаниями;
   - для каждой позиции выводится статус «задана» / «не задана» (например, по правилу: (0, 0) — не задана).
3. Пользователь вводит номер координаты (или относительного движения), которую хочет задать.
4. Программа выводит название и описание выбранной координаты и сообщение: «Наведите курсор на нужный элемент и нажмите Ctrl+Shift+P».
5. Включается режим захвата: следующий вызов «получить координаты курсора» (Ctrl+Shift+P) не просто печатает (x, y), а записывает их в выбранную координату и сохраняет в файл, затем выходит из режима захвата.
6. Пользователь наводит курсор на элемент интерфейса (поле ввода, кнопку и т.д.) и нажимает Ctrl+Shift+P.
7. Текущие (x, y) курсора записываются в выбранную координату, данные сохраняются в файл, режим захвата сбрасывается.

Итого: два шага — «выбрать, какую координату настраивать» (меню по горячей клавише) и «зафиксировать позицию» (Ctrl+Shift+P). Координаты хранятся в файле и загружаются при старте.

### 6.2. Список координат (по текущей программе)

- Абсолютные координаты (точки клика): `PROMPT_INPUT`, `IMAGE_LOCATION`, `NEW_CHAT_BUTTON`, `CHAT_NAME_INPUT`, `CHAT_NAME_POPUP`, `CHAT_NAME_CONFIRM`, `ASPECT_RATIO_SELECTOR`, при необходимости `PROMPT_INPUT_AFTER_IMAGE`.
- Относительные движения: `TO_SAVE_OPTION` — смещение от точки клика к пункту «Сохранить изображение» в контекстном меню.

Для режимов, где не используется выбор соотношения сторон или поле после изображения, соответствующие координаты можно не задавать (или помечать как необязательные в меню).

## 7. Рабочее окно браузера

Способ настройки в v2 — тот же, что в текущей программе.

### 7.1. Текущий способ настройки окна (сохраняем в v2)

- Горячая клавиша (в текущей программе — Ctrl+Shift+V) вызывает настройку рабочего окна.
- Алгоритм:
  1. Поиск уже открытого окна браузера (по заголовку: Chrome, Firefox, Edge и т.п.).
  2. Если окно найдено — активация, изменение размера (например, 1200×1000) и перемещение в позицию (0, 0).
  3. Если окно не найдено или настроить не удалось — при необходимости создание нового окна браузера (запуск браузера с параметрами размера/позиции), затем поиск созданного окна и та же настройка размера и позиции.
- Результат: окно браузера фиксированного размера в фиксированной позиции, чтобы координаты интерфейса были стабильными.

В v2 сохраняем этот сценарий: одна горячая клавиша «Настроить рабочее окно» без дополнительных настроек в общем списке настроек (размер/позиция могут быть константами в коде или вынесены в конфиг по желанию).

---

## 8. Что не добавляем

- **SAVE_FOLDER** — не добавляем.
- **LOG_ENABLED** — не добавляем; логирование всегда включено.
- **GENERATIONS_PER_CARD** — не добавляем; количество генераций на карточку определяется только из файла промптов.

---

## 9. Настройки API (интеграция Gemini API)

Новые настройки для генерации изображений через Gemini API (без браузера).

| Ключ                  | Тип   | Описание                                                                                     | Как задаётся                                                            |
| --------------------- | ----- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `GENERATION_METHOD`   | str   | Метод генерации: `"browser"` (через браузер) или `"api"` (через Gemini API)                  | Пункт меню «Выбрать метод генерации» (выбор из 2 вариантов)             |
| `API_KEY`             | str   | API ключ Google AI Studio (получить на https://aistudio.google.com/apikey)                   | Пункт меню «Настроить API ключ» (ввод строки)                           |
| `API_MODEL`           | str   | Название модели (`"gemini-2.5-flash-image"` или `"gemini-3-pro-image-preview"`)              | Автоматически (по умолчанию `gemini-2.5-flash-image`)                   |
| `API_IMAGE_SIZE`      | str   | Разрешение изображения для Pro модели (`"1K"`, `"2K"`, `"4K"`; для flash не применяется)     | Автоматически (по умолчанию `"1K"`)                                      |
| `API_TIMEOUT`         | float | Таймаут API запросов в секундах (по умолчанию 60.0)                                          | Автоматически                                                           |

**Примечания:**

- При `GENERATION_METHOD = "api"` не требуется настройка координат (Ctrl+0, Ctrl+Shift+P) и окна браузера (Ctrl+Shift+V).
- API режим поддерживает режимы `standard` и `multiformat`, но пока не поддерживает `multiformat_with_refs`.
- Для API режима используются те же настройки `FACE_ASPECT_RATIO` и `BACK_ASPECT_RATIO` (для мультиформата).
- API ключ проверяется на валидность (должен начинаться с `"AIza"` и иметь ~39 символов).

## 10. Краткая сводка ключей настроек v2

| Ключ                    | Назначение                                                               |
| ----------------------- | ------------------------------------------------------------------------ |
| `CURRENT_SITE`          | Выбранный сайт                                                           |
| `CURRENT_MODE`          | Выбранный режим сайта                                                    |
| `PROMPTS_FILE`          | Путь к файлу промптов (выбор через список файлов в `data/`)              |
| `START_FROM_CARD`       | С какой карточки начинать                                                |
| `END_CARD`              | До какой карточки обрабатывать                                           |
| `CARDS_TO_PROCESS`      | Вычисляемое: количество карточек                                         |
| `GENERATION_WAIT`       | Таймаут ожидания генерации (сек) — для браузерного режима                |
| `IMAGE_WAIT_INTERVAL`   | Интервал между проверками готовности изображения (сек) — для браузера    |
| `CHECK_IMAGE_GENERATED` | Вкл/выкл проверки по скриншоту и раннего выхода из ожидания — для браузера |
| `FACE_ASPECT_RATIO`     | Соотношение сторон для лицевой стороны (обязательно)                     |
| `BACK_ASPECT_RATIO`     | Соотношение сторон для оборота (опционально для режимов без двух сторон) |
| `GENERATION_METHOD`     | Метод генерации: `"browser"` или `"api"`                                  |
| `API_KEY`               | API ключ Google AI Studio (для метода `"api"`)                           |
| `API_MODEL`             | Название модели API (для метода `"api"`)                                 |
| `API_IMAGE_SIZE`        | Разрешение изображения (для метода `"api"` с Pro моделью)                |
| `API_TIMEOUT`           | Таймаут API запросов (сек, для метода `"api"`)                           |

Координаты и относительные движения — отдельное хранилище (например, `coordinates.json`). Настройка координат — меню по горячей клавише + фиксация позиции по Ctrl+Shift+P. Настройка окна — одна горячая клавиша «Настроить рабочее окно». **Координаты не требуются при `GENERATION_METHOD = "api"`.**
