# Правила именования чатов и файлов

Стандарты формирования имён чатов в AI Studio и файлов сохраняемых изображений.

---

## 1. Общие правила

### 1.1. Безопасные символы

При формировании имён заменяются:

- Пробелы ` ` → `_`
- Слэши `/` и `\` → `_`
- Двоеточие `:` → `x` (для соотношений сторон)

Удаляются:

- Символы: `*`, `?`, `"`, `<`, `>`, `|`

### 1.2. Функция преобразования

```python
def safe_name(text):
    """
    Преобразует текст в безопасное имя для файла/чата.
    """
    safe = text.replace(" ", "_").replace("/", "_").replace("\\", "_")
    for char in ['*', '?', '"', '<', '>', '|']:
        safe = safe.replace(char, '')
    return safe

def safe_format(ratio):
    """
    Преобразует соотношение сторон в безопасную строку.
    Пример: "4:3" → "4x3"
    """
    return ratio.replace(":", "x")
```

## 2. Режим standard

### 2.1. Имя чата

```
Карточка {card_number} - генерация {gen_num}
```

**Примеры**:
| card_number | gen_num | Имя чата |
|-------------|---------|----------|
| 1 | 1 | `Карточка 1 - генерация 1` |
| 1 | 2 | `Карточка 1 - генерация 2` |
| 5 | 1 | `Карточка 5 - генерация 1` |

### 2.2. Имя файла

Единый формат (сторона по умолчанию — **лицевая**):

```
Карточка_{номер}_лицевая_промпт_{номер_промпта}.png
```

**Примеры**:
| card_number | gen_num | Имя файла |
|-------------|---------|-----------|
| 1 | 1 | `Карточка_1_лицевая_промпт_1.png` |
| 1 | 2 | `Карточка_1_лицевая_промпт_2.png` |
| 5 | 3 | `Карточка_5_лицевая_промпт_3.png` |

---

## 3. Режим multiformat

### 3.1. Имя чата

```
Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}
```

**Примеры**:
| card_number | card_name | side | pair_number | Имя чата |
|-------------|-----------|------|-------------|----------|
| 63 | Нефть | лицо | 1 | `Карточка 63 - Нефть - лицо - Промпт 1` |
| 63 | Нефть | оборот | 1 | `Карточка 63 - Нефть - оборот - Промпт 1` |
| 20 | Балтийское море | лицо | 2 | `Карточка 20 - Балтийское море - лицо - Промпт 2` |

### 3.2. Имя файла

Единый формат (сторона: **лицо** или **оборот**):

```
Карточка_{номер}_{сторона_карточки}_промпт_{номер_промпта}.png
```

**Примеры**:
| card_number | side | pair_number | Имя файла |
|-------------|------|-------------|-----------|
| 63 | лицо | 1 | `Карточка_63_лицо_промпт_1.png` |
| 63 | оборот | 1 | `Карточка_63_оборот_промпт_1.png` |
| 20 | лицо | 2 | `Карточка_20_лицо_промпт_2.png` |

---

## 4. Режим multiformat_with_refs

### 4.1. Имя чата

Такое же, как в `multiformat`:

```
Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}
```

Референс **не отражается** в имени чата.

### 4.2. Имя файла

Формат с названием карточки (для отбора изображений по теме):

```
Карточка_{номер}_{safe_card_name}_{сторона}_промпт_{номер_промпта}.png
```

Где `safe_card_name` — название карточки с заменой пробелов на `_` и удалением спецсимволов (REFERENCES_format п.4). Референс **не отражается** в имени файла.

**Примеры**:
| card_number | card_name | side | pair_number | Имя файла |
|-------------|-----------|------|-------------|-----------|
| 63 | Нефть | лицо | 1 | `Карточка_63_Нефть_лицо_промпт_1.png` |
| 63 | Нефть | оборот | 1 | `Карточка_63_Нефть_оборот_промпт_1.png` |
| 20 | Балтийское море | лицо | 1 | `Карточка_20_Балтийское_море_лицо_промпт_1.png` |

## 5. Референсные изображения

### 5.1. Структура папок

```
data/images/лицо/{filename}
data/images/оборот/{filename}
```

### 5.2. Имя файла референса

Поддерживаются **два формата**:

**Упрощенный (рекомендуется):**
```
{card_number}_{side}.{ext}
```

**Примеры**:
| card_number | side   | Имя файла        |
|-------------|--------|------------------|
| 3           | лицо   | `3_лицо.png`     |
| 11          | лицо   | `11_лицо.png`    |
| 20          | оборот | `20_оборот.jpg`  |

**Полный (опциональный):**
```
{side}_{card_number}_{safe_card_name}.{ext}
```

**Примеры**:
| card_number | card_name       | side   | Имя файла                         |
|-------------|-----------------|--------|-----------------------------------|
| 63          | Нефть           | лицо   | `лицо_63_Нефть.png`               |
| 63          | Нефть           | оборот | `оборот_63_Нефть.png`             |
| 20          | Балтийское море | лицо   | `лицо_20_Балтийское_море.png`     |
| 5           | Порт/Гавань     | оборот | `оборот_5_Порт_Гавань.jpg`        |

## 7. Код формирования имён

### 7.1. Для standard

```python
def make_chat_name_standard(card_number, gen_num):
    """Формирует имя чата для стандартного режима."""
    return f"Карточка {card_number} - генерация {gen_num}"

def make_filename_standard(card_number, gen_num):
    """Формирует имя файла для стандартного режима (сторона — лицевая)."""
    return f"Карточка_{card_number}_лицевая_промпт_{gen_num}.png"
```

### 7.2. Для multiformat

```python
def make_chat_name_multiformat(card_number, card_name, side, pair_number):
    """Формирует имя чата для мультиформатного режима."""
    return f"Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}"

def make_filename_multiformat(card_number, side, pair_number):
    """Формирует имя файла для мультиформатного режима (сторона: лицо/оборот)."""
    return f"Карточка_{card_number}_{side}_промпт_{pair_number}.png"
```

### 7.3. Для multiformat_with_refs

```python
def make_filename_multiformat_with_refs(card_number, card_name, side, pair_number):
    """Формирует имя файла для режима с референсами (название карточки в имени)."""
    safe_card_name = safe_name(card_name)
    return f"Карточка_{card_number}_{safe_card_name}_{side}_промпт_{pair_number}.png"
```

### 7.4. Для референсов

```python
def make_reference_filename(side, card_number, card_name, ext="png"):
    """Формирует ожидаемое имя файла референса."""
    safe_card_name = safe_name(card_name)
    return f"{side}_{card_number}_{safe_card_name}.{ext}"
```

## 8. Ограничения

### 8.1. Длина имени файла

Windows ограничивает путь до **260 символов** (или **32767** с длинными путями).

Если имя слишком длинное:

- Сокращается `card_name` (первые 30 символов)
- Логируется предупреждение

### 8.2. Кириллица

Кириллица **поддерживается** в именах файлов и чатов:

- Кодировка UTF-8
- Windows NTFS поддерживает кириллицу
