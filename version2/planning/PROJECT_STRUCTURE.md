# Структура проекта v2

Актуальная структура рабочего приложения. Исторические планы миграции лежат в
этом же каталоге, но не описывают текущее дерево файлов.

```
matfocus-auto-gen/
├── main.py                         # Точка входа: горячие клавиши, меню и agent CLI
├── ui/                             # Консоль, меню и горячие клавиши
├── sites/aistudio/                 # Браузерные и API-режимы Google AI Studio
├── utils/                          # API, процессы, настройки, пути и логи
├── data/                           # Настройки, координаты и локальные входные данные
├── tests/                          # Контрактные тесты активного v2
├── aistudio-ratio/                 # Независимое вручную подключаемое расширение Chrome
├── version2/reference/             # Актуальные контракты и руководства
├── version2/planning/              # История проектирования и аудит
└── requirements.txt                # Зависимости Python
```

## Основные слои

| Слой | Назначение |
| --- | --- |
| `main.py` | Выбирает agent CLI, консольное меню или интерактивный запуск. |
| `ui/` | Взаимодействие с пользователем и запуск операций. |
| `sites/aistudio/` | Парсинг промптов и реализация трёх режимов генерации. |
| `utils/process_control.py` | Единственный слой управления воркер-процессом. |
| `utils/settings_store.py` | Загрузка и безопасное сохранение настроек. |
| `utils/coordinates_store.py` | Загрузка и сохранение координат браузерного режима. |
| `utils/agent_cli.py` | Машинный интерфейс `agent-plan` и `agent-run-api`. |

## Данные и результаты

- `data/settings.json` — отслеживаемые безопасные настройки без секретов.
- `data/coordinates.json` и файлы промптов — локальные пользовательские данные.
- `generated_images/` и `logs/` — результаты запусков, игнорируемые Git.
- API-ключи задаются в окружении или локальном `.env`.

## Границы

В репозитории нет исполняемого слоя v1, совместимых менеджеров процессов или
старых тестов. Браузерные режимы v2 остаются поддерживаемой частью приложения.
`aistudio-ratio/` не входит в Python runtime и загружается Chrome вручную.
