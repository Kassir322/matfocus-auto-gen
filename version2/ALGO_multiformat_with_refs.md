# Алгоритм режима multiformat_with_refs

Пошаговое описание работы режима с референсными изображениями.

---

## 1. Общее описание

Режим `multiformat_with_refs` — расширение мультиформатного режима. Перед вводом промпта в чат **вставляется референсное изображение** из локальной папки.

Референс используется как визуальная подсказка для нейросети, чтобы результат был похож на референс по стилю/композиции.

---

## 2. Отличия от multiformat

| Аспект                    | multiformat        | multiformat_with_refs           |
| ------------------------- | ------------------ | ------------------------------- |
| Референсы                 | Не используются    | Обязательны                     |
| Дополнительная координата | —                  | `PROMPT_INPUT_AFTER_IMAGE`      |
| Проверка перед стартом    | Только координаты  | Координаты + наличие референсов |
| Порядок действий          | Промпт → Генерация | Референс → Промпт → Генерация   |

---

## 3. Используемые координаты

Все из режима `multiformat` плюс:

| Ключ                       | Тип         | Описание                                         | Обязательность  |
| -------------------------- | ----------- | ------------------------------------------------ | --------------- |
| `PROMPT_INPUT_AFTER_IMAGE` | coordinates | **Поле ввода промпта после вставки изображения** | **Обязательно** |

Это нужно, потому что после вставки изображения фокус может перейти на другой элемент, и нужно явно кликнуть в поле ввода промпта.

---

## 4. Используемые настройки

Все из режима `multiformat`, без дополнительных настроек.

## 6. Формат имени референса

```
{side}_{card_number}_{safe_card_name}.{ext}
```

Где:

- `side` = `"лицо"` или `"оборот"`
- `card_number` = номер карточки
- `safe_card_name` = название карточки, пробелы заменены на `_`
- `ext` = `png` или `jpg`

Примеры:

- `лицо_1_Карточка_1.png`
- `оборот_20_Балтийское_море.jpg`
- `лицо_63_Нефть.png`

---

## 7. Алгоритм поиска референса

Функция `get_reference_path(side, card_number, card_name)`:

```python
def get_reference_path(side, card_number, card_name):
    """
    Ищет файл референса для указанной стороны и карточки.

    Возвращает:
    - Путь к файлу (str), если найден
    - None, если не найден
    """
    # Формируем безопасное имя
    safe_name = card_name.replace(" ", "_").replace("/", "_").replace("\\", "_")

    # Базовый путь
    base_folder = f"data/images/{side}"

    # Ищем в двух расширениях
    for ext in ["png", "jpg"]:
        filename = f"{side}_{card_number}_{safe_name}.{ext}"
        full_path = os.path.join(base_folder, filename)

        if os.path.exists(full_path):
            return full_path

    return None
```

## 8. Проверка референсов перед стартом

Перед началом генерации:

```
1. Загрузить все пары промптов из файла

2. Для каждой пары:
   - Проверить наличие референса для лицевой стороны
   - Проверить наличие референса для оборотной стороны
   - Если референс не найден → добавить в список отсутствующих

3. Если список отсутствующих не пуст:
   - Вывести список: "⚠️ Отсутствуют референсы:"
   - Для каждого: "  - {side} карточки {card_number} ({card_name})"
   - Спросить: "Продолжить без них? (y/n)"
   - Если n → отмена запуска

4. Если все референсы на месте:
   - Вывести: "✓ Все референсы найдены"
   - Продолжить генерацию
```

## 9. Алгоритм генерации одной стороны с референсом

Функция `generate_single_side_with_ref(card_number, card_name, pair_number, side, prompt, format_ratio, stop_event)`:

```
1. Найти референс:
   ref_path = get_reference_path(side, card_number, card_name)

2. Если референс не найден:
   - Логирование: "⚠️ Референс не найден для {side} карточки {card_number}"
   - Продолжить без референса (как обычный multiformat)
   - ИЛИ пропустить (зависит от настройки)

3. Сформировать имя чата и имя файла

4. Логирование: "--- Генерация: {chat_name} (с референсом) ---"

5. Создать новый чат:
   - Клик по NEW_CHAT_BUTTON
   - Пауза NEW_CHAT_WAIT

6. *** ВСТАВИТЬ РЕФЕРЕНС ***
   - Скопировать файл референса в буфер обмена (как файл)
   - Клик по PROMPT_INPUT
   - Вставить изображение (Ctrl+V)
   - Пауза AFTER_IMAGE_PASTE (2 сек)

7. Кликнуть в поле промпта ПОСЛЕ изображения:
   - Клик по PROMPT_INPUT_AFTER_IMAGE
   - Пауза BETWEEN_CLICKS

8. Ввести промпт:
   - Скопировать текст промпта в буфер обмена
   - Вставить (Ctrl+V)
   - Пауза AFTER_PASTE

9. Переименовать чат:
   - Клик по CHAT_NAME_INPUT
   - Вставить название чата
   - Enter
   - Пауза CHAT_RENAME_WAIT

10. Выбрать соотношение сторон:
    - Клик по ASPECT_RATIO_SELECTOR
    - Ввести format_ratio
    - Enter
    - Пауза BETWEEN_CLICKS

11. Вернуться к полю ввода:
    - Клик по PROMPT_INPUT_AFTER_IMAGE
    - Пауза BETWEEN_CLICKS

12. Запустить генерацию:
    - Нажать Ctrl+Enter

13. Ожидание генерации (как в multiformat)

14. Сохранить изображение (как в multiformat)

15. Логирование: "Генерация {chat_name} завершена успешно (с референсом)"
```

## 10. Копирование изображения в буфер обмена

Для вставки референса используется копирование **файла** в буфер обмена:

```python
import win32clipboard
import win32con
from PIL import Image
import io

def copy_image_to_clipboard(image_path):
    """
    Копирует изображение в буфер обмена.
    Windows-специфичная реализация.
    """
    # Открыть изображение
    image = Image.open(image_path)

    # Конвертировать в BMP для буфера
    output = io.BytesIO()
    image.convert("RGB").save(output, "BMP")
    data = output.getvalue()[14:]  # Убрать BMP header
    output.close()

    # Записать в буфер обмена
    win32clipboard.OpenClipboard()
    win32clipboard.EmptyClipboard()
    win32clipboard.SetClipboardData(win32con.CF_DIB, data)
    win32clipboard.CloseClipboard()
```

Дополнительные логи:

| ---- | -------------------------------------------------------------- | ---------------- |
| `🖼️` | `🖼️ Вставлен референс: data/images/лицо/лицо_1_Карточка_1.png` | После вставки    |

| `📁` | `📁 Проверка референсов: 40/40 найдено`                        | Перед стартом    |

---

## 14. Обработка ошибок

1. **Референс не найден**:
   - Если разрешено продолжение → генерация без референса (как multiformat).
   - Если не разрешено → пропуск стороны.

2. **Ошибка копирования в буфер**:
   - Логирование ошибки.
   - Попытка продолжить без референса.

3. **Неверный формат файла**:
   - Поддерживаются только PNG и JPG.
   - Другие форматы игнорируются при поиске.
