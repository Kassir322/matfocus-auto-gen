# Алгоритм режима multiformat

Пошаговое описание работы мультиформатного режима генерации изображений (лицо + оборот с разными соотношениями сторон).

---

## 1. Общее описание

Мультиформатный режим (`multiformat`) предназначен для генерации **пар изображений** — лицевая и оборотная сторона карточки с разными соотношениями сторон.

Каждая сторона создаётся в **отдельном чате** с выбором соответствующего формата (aspect ratio).

---

## 2. Используемые координаты

| Ключ                    | Тип                | Описание                                        | Обязательность  |
| ----------------------- | ------------------ | ----------------------------------------------- | --------------- |
| `PROMPT_INPUT`          | coordinates        | Поле ввода промпта                              | Обязательно     |
| `IMAGE_LOCATION`        | coordinates        | Место клика на сгенерированное изображение      | Обязательно     |
| `NEW_CHAT_BUTTON`       | coordinates        | Кнопка создания нового чата                     | Обязательно     |
| `CHAT_NAME_INPUT`       | coordinates        | Поле ввода названия чата                        | Обязательно     |
| `ASPECT_RATIO_SELECTOR` | coordinates        | **Выпадающий список выбора соотношения сторон** | **Обязательно** |
| `CHAT_NAME_POPUP`       | coordinates        | Поле ввода в попапе (если есть)                 | Опционально     |
| `CHAT_NAME_CONFIRM`     | coordinates        | Кнопка подтверждения в попапе                   | Опционально     |
| `TO_SAVE_OPTION`        | relative_movements | Смещение к пункту "Сохранить изображение"       | Обязательно     |

---

## 3. Используемые настройки

| Ключ                    | Тип   | Описание                                                     |
| ----------------------- | ----- | ------------------------------------------------------------ |
| `PROMPTS_FILE`          | str   | Путь к файлу с промптами                                     |
| `START_FROM_CARD`       | int   | С какой карточки начинать                                    |
| `END_CARD`              | int   | До какой карточки обрабатывать                               |
| `GENERATION_WAIT`       | float | Время ожидания генерации (секунды)                           |
| `CHECK_IMAGE_GENERATED` | bool  | Включить проверку готовности изображения                     |
| `IMAGE_WAIT_TIME`       | float | Время упрощённого ожидания (если проверка включена)          |
| `IMAGE_CHECK_ATTEMPTS`  | int   | Количество попыток проверки                                  |
| `IMAGE_CHECK_DELAY`     | int   | Секунд между попытками                                       |
| `FACE_ASPECT_RATIO`     | str   | Соотношение сторон для лицевой стороны (например, `"4:3"`)   |
| `BACK_ASPECT_RATIO`     | str   | Соотношение сторон для оборотной стороны (например, `"3:2"`) |

---

## 4. Алгоритм работы (верхний уровень)

```
automation_worker(start_card, ..., cards_to_process)
│
├── 1. Загрузить промпты из файла (FileHandler → MultiFormatParser)
│
├── 2. Получить список карточек для обработки:
│      - от START_FROM_CARD до END_CARD
│      - каждая карточка содержит список пар промптов
│
├── 3. Вывести сводку:
│      - "Режим: Мультиформатный (лицо {face_ratio} + оборот {back_ratio})"
│      - "Будет обработано N карточек"
│      - "Найдено M пар промптов"
│      - "Будет создано M*2 изображений"
│
├── 4. Цикл по карточкам:
│      │
│      └── process_card(card_number, card_name, pairs_list, stop_event)
│           │
│           ├── Цикл по парам:
│           │    └── generate_pair(card_number, card_name, pair_number, prompts_dict, stop_event)
│           │         │
│           │         ├── generate_single_side(..., side="лицо", format=FACE_ASPECT_RATIO)
│           │         │
│           │         ├── Пауза BETWEEN_GENERATIONS
│           │         │
│           │         └── generate_single_side(..., side="оборот", format=BACK_ASPECT_RATIO)
│           │
│           └── Пауза BETWEEN_CARDS между карточками
│
└── 5. Вывести итоговый отчёт:
       - "Обработано карточек: X/Y"
       - "Обработано пар: X/Y"
       - "Создано изображений: X/Y"
```

## 5. Алгоритм генерации одной стороны

Функция `generate_single_side(card_number, card_name, pair_number, side, prompt, format_ratio, stop_event)`:

```
1. Сформировать имя чата и имя файла

2. Логирование: "--- Генерация: {chat_name} ---"

3. Создать новый чат:
   - Клик по NEW_CHAT_BUTTON
   - Пауза NEW_CHAT_WAIT

4. Ввести промпт:
   - Клик по PROMPT_INPUT
   - Пауза BETWEEN_CLICKS
   - Вставить текст промпта через буфер обмена (Ctrl+V)
   - Пауза AFTER_PASTE

5. Переименовать чат:
   - Клик по CHAT_NAME_INPUT
   - Вставить название чата
   - Enter
   - Пауза CHAT_RENAME_WAIT

6. Выбрать соотношение сторон:
   - Клик по ASPECT_RATIO_SELECTOR
   - Пауза BETWEEN_CLICKS
   - Ввести format_ratio (например, "4:3")
   - Пауза BETWEEN_CLICKS
   - Enter для подтверждения
   - Пауза BETWEEN_CLICKS

7. Вернуться к полю ввода промпта:
   - Клик по PROMPT_INPUT
   - Пауза BETWEEN_CLICKS

8. Запустить генерацию:
   - Нажать Ctrl+Enter
   - Пауза BETWEEN_CLICKS

9. Ожидание генерации:
   - Если CHECK_IMAGE_GENERATED = True:
     - Начальное ожидание (5 сек или половина GENERATION_WAIT)
     - Цикл проверок (IMAGE_CHECK_ATTEMPTS раз):
       - Проверить изображение
       - Если готово → выход
       - Иначе → ждать IMAGE_CHECK_DELAY и повторить
   - Если CHECK_IMAGE_GENERATED = False:
     - Просто ждать GENERATION_WAIT секунд

10. Сохранить изображение:
    - Скопировать имя файла в буфер
    - ПКМ по IMAGE_LOCATION
    - Переместить на TO_SAVE_OPTION
    - Клик
    - Вставить имя файла (Ctrl+V)
    - Enter
    - Восстановить буфер

11. Логирование: "Генерация {chat_name} завершена успешно"
```

---

## 6. Порядок обработки пары

Для каждой пары промптов:

1. **Лицевая сторона** (side = "лицо"):
   - Формат: `FACE_ASPECT_RATIO` (по умолчанию `4:3`)
2. Пауза `BETWEEN_GENERATIONS`

3. **Оборотная сторона** (side = "оборот"):
   - Формат: `BACK_ASPECT_RATIO` (по умолчанию `3:2`)

Если промпт для какой-то стороны отсутствует (None) — эта сторона пропускается с предупреждением.

---

## 7. Формат имени чата

```
Карточка {card_number} - {card_name} - {side} - Промпт {pair_number}
```

Примеры:

- `Карточка 63 - Нефть - лицо - Промпт 1`
- `Карточка 63 - Нефть - оборот - Промпт 1`
- `Карточка 63 - Нефть - лицо - Промпт 2`

---

## 8. Формат имени файла

```
Карточка_{card_number}_{safe_card_name}_{side}_промпт_{pair_number}_{format}.png
```

Где:

- `safe_card_name` = название с заменой пробелов, `/`, `\` на `_`
- `format` = соотношение сторон с заменой `:` на `x` (например, `4x3`, `3x2`)

Примеры:

- `Карточка_63_Нефть_лицо_промпт_1_4x3.png`
- `Карточка_63_Нефть_оборот_промпт_1_3x2.png`
- `Карточка_63_Балтийское_море_лицо_промпт_2_4x3.png`

---

## 9. Логирование

| Тег        | Пример                                            | Когда           |
| ---------- | ------------------------------------------------- | --------------- |
| `🔗`       | `======= 🔗 ГЕНЕРАЦИЯ ПАРЫ 1 КАРТОЧКИ 63 =======` | Начало пары     |
| `📦`       | `======= 📦 ОБРАБОТКА КАРТОЧКИ #63 =======`       | Начало карточки |
| `✓`        | `✓ Пара 1 завершена: 2/2 изображений`             | Завершение пары |
| `⚠️`       | `⚠️ Пропуск лицевой стороны (промпт отсутствует)` | Неполная пара   |
| `📋 ОТЧЁТ` | `========== 📋 ОТЧЁТ ==========`                  | Итоги           |

Сводка в конце:

```
📦 Обработано карточек: X/Y
🔗 Обработано пар: X/Y
🖼️ Создано изображений: X/Y
```

---

## 10. Обработка неполных пар

Если в файле промптов есть только "лицо" без "оборота" (или наоборот):

1. Парсер добавляет пару с `None` для отсутствующей стороны.
2. При генерации проверяется: `if face_prompt is not None` / `if back_prompt is not None`.
3. Отсутствующая сторона пропускается с логом: `"⚠️ Пропуск {стороны} пары N (промпт отсутствует)"`.
4. Счётчик ожидаемых изображений учитывает неполные пары.

---

## 11. Проверка координат перед стартом

Перед началом работы проверяются критичные координаты:

- `PROMPT_INPUT`
- `IMAGE_LOCATION`
- `NEW_CHAT_BUTTON`
- `CHAT_NAME_INPUT`
- `ASPECT_RATIO_SELECTOR` — **обязательно для multiformat**

Если `ASPECT_RATIO_SELECTOR` не задан (0, 0), выводится ошибка и генерация не запускается.

- Паузы при выборе формата (BETWEEN_CLICKS после каждого шага).
