# Решение проблем (Troubleshooting)

Частые проблемы и способы их решения.

---

## 1. Проблемы с координатами

### 1.1. Координата (0, 0)

**Симптом**: Программа сообщает `"Координата не задана"` или клик происходит в верхнем левом углу экрана.

**Причина**: Координата не была настроена.

**Решение**:

1. Нажмите `Ctrl+0`
2. Выберите координату
3. Наведите курсор на нужный элемент
4. Нажмите `Ctrl+Shift+P`

---

### 1.2. Клик попадает не туда

**Симптом**: Программа кликает, но не в тот элемент.

**Причины**:

- Окно браузера переместилось
- Изменился масштаб страницы
- Изменилось разрешение экрана

**Решение**:

1. Верните браузер в исходное положение
2. Установите масштаб 100% (Ctrl+0 в браузере)
3. Перенастройте координаты (`Ctrl+0` в программе)

---

### 1.3. Не сохраняется изображение

**Симптом**: Генерация проходит, но файл не появляется.

**Причины**:

- Неверная координата `IMAGE_LOCATION`
- Неверное смещение `TO_SAVE_OPTION`
- Диалог сохранения не открывается

**Решение**:

1. Перенастройте `IMAGE_LOCATION` точно на центр изображения
2. Перенастройте `TO_SAVE_OPTION`:
   - ПКМ на изображении
   - Наведите на "Сохранить изображение как..."
   - `Ctrl+Shift+P`
3. Проверьте папку загрузок по умолчанию в браузере

---

## 2. Проблемы с окном

### 2.1. Не находится окно браузера

**Симптом**: При нажатии `Ctrl+Shift+V` выводится ошибка.

**Причины**:

- Браузер не открыт
- Окно свёрнуто
- Окно на другом рабочем столе

**Решение**:

1. Откройте браузер с AI Studio
2. Разверните окно
3. Нажмите `Ctrl+Shift+V` снова

---

### 2.2. Фокус теряется во время работы

**Симптом**: Программа начинает кликать не в браузер.

**Причины**:

- Всплыло уведомление
- Открылось другое окно
- Сработала другая программа

**Решение**:

1. Нажмите `Esc` для остановки
2. Отключите уведомления Windows
3. Закройте лишние программы
4. Перезапустите генерацию

---

## 3. Проблемы с генерацией

### 3.1. Таймаут истекает до готовности изображения

**Симптом**: Программа сохраняет пустое место или индикатор загрузки.

**Причина**: `GENERATION_WAIT` слишком маленький.

**Решение**:

1. Увеличьте `GENERATION_WAIT` (например, до 60-90 секунд)
2. Нажмите `Ctrl+3` для настройки

---

### 3.2. Проверка изображения не работает

**Симптом**: Программа не определяет, что изображение готово.

**Причины**:

- Неверная координата `IMAGE_LOCATION`
- Слишком высокий `IMAGE_CHECK_THRESHOLD`
- Изображение очень тёмное/светлое

**Решение**:

1. Отключите проверку: `Ctrl+4` (установить `CHECK_IMAGE_GENERATED = False`)
2. Используйте фиксированное ожидание

---

### 3.3. Генерация не запускается (Ctrl+Enter не работает)

**Симптом**: Промпт введён, но генерация не начинается.

**Причины**:

- Фокус не в поле ввода
- Горячая клавиша заблокирована

**Решение**:

1. Перенастройте `PROMPT_INPUT`
2. Убедитесь, что после ввода промпта курсор в поле ввода

---

## 4. Проблемы с файлом промптов

### 4.1. Файл не распознаётся

**Симптом**: `"Загружено 0 карточек"` или ошибка парсинга.

**Причины**:

- Неверный формат строк
- Неверная кодировка файла
- Лишние пробелы/символы

**Решение**:

1. Проверьте формат:
   - standard: `Карточка N - Промпт M: текст`
   - multiformat: `Карточка N сторона Название - Промпт M: текст`
2. Сохраните файл в UTF-8
3. Удалите лишние пробелы в начале строк

---

### 4.2. Карточка пропускается

**Симптом**: Некоторые карточки не обрабатываются.

**Причины**:

- Номер карточки вне диапазона `START_FROM_CARD` — `END_CARD`
- Пустой промпт

**Решение**:

1. Проверьте диапазон карточек в настройках
2. Убедитесь, что промпты не пустые

---

## 5. Проблемы с референсами

### 5.1. Референс не найден

**Симптом**: `"[WARN] Референс не найден: лицо_N_Название.png"`

**Причины**:

- Файл отсутствует
- Неверное имя файла
- Файл в неправильной папке

**Решение**:

1. Проверьте структуру папок:
   ```
   data/images/лицо/{side}_{N}_{Name}.png
   data/images/оборот/{side}_{N}_{Name}.png
   ```
2. Проверьте имя файла:
   - Пробелы заменены на `_`
   - Название совпадает с файлом промптов
3. Расширение `.png` или `.jpg` (не `.jpeg`)

---

### 5.2. Референс не вставляется

**Симптом**: Изображение не появляется в чате.

**Причины**:

- Проблема с буфером обмена
- Формат изображения не поддерживается

**Решение**:

1. Попробуйте вручную: скопировать файл → вставить в чат
2. Конвертируйте изображение в PNG

---

## 6. Системные проблемы

### 6.1. Ошибка импорта модуля

**Симптом**: `ModuleNotFoundError: No module named 'pyautogui'`

**Решение**:

```bash
pip install -r requirements.txt
```

---

### 6.2. Ошибка доступа к буферу обмена

**Симптом**: `win32clipboard error` или подобное.

**Причины**:

- Буфер обмена занят другой программой
- Проблемы с pywin32

**Решение**:

1. Закройте программы, использующие буфер (менеджеры буфера)
2. Переустановите pywin32:
   ```bash
   pip uninstall pywin32
   pip install pywin32
   ```

---

### 6.3. Программа не реагирует на Esc

**Симптом**: После нажатия Esc генерация продолжается.

**Причина**: В v1 это было известной проблемой.

**Решение в v2**: Esc вызывает `terminate()` — мгновенная остановка.

Если всё ещё не работает:

1. `Ctrl+C` в консоли
2. Закрыть окно консоли

---

## 7. Диагностика

### 7.1. Проверка координат

```
Ctrl+0 → Посмотреть список координат

Все должны быть "✓ задана" (кроме опциональных)
```

### 7.2. Проверка настроек

```
Ctrl+5 → Показать текущие настройки
```

### 7.3. Проверка логов

Откройте последний файл лога в папке `logs/` (имя вида `auto-gen_YYYY-MM-DD_HH-MM-SS.log`). Формат строк: дата и время, затем тег и сообщение (LOGGING.md):

```
2024-01-15 10:30:00 [PLAN] Режим: standard. Карточек: 10, генераций: 24
2024-01-15 10:30:01 [CARD] Карточка 1
2024-01-15 10:30:25 [OK] Файл сохранён: Карточка_1_лицевая_промпт_1.png
2024-01-15 10:30:50 [ERROR] Ошибка при сохранении: ...
```

### 7.4. Тестовая генерация

1. Создайте файл с 1 карточкой и 1 промптом
2. Запустите генерацию
3. Наблюдайте за каждым шагом
4. Найдите, где происходит сбой

---

## 8. Сброс к заводским настройкам

Если ничего не помогает:

1. Удалите файлы данных:

   ```
   del data/settings.json
   del data/coordinates.json
   ```

2. Перезапустите программу — файлы создадутся заново

3. Настройте всё с нуля

---

## 9. Получение помощи

### Информация для отчёта об ошибке

1. Версия Python: `python --version`
2. Версия ОС
3. Содержимое последнего файла в `logs/` (последние 50 строк)
4. Содержимое `data/settings.json`
5. Содержимое `data/coordinates.json`
6. Описание проблемы и шаги для воспроизведения
