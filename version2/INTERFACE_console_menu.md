# Интерфейс консольного меню v2 (простая текстовая панель управления)

Спецификация модуля консольного меню (например, `ui/console_menu.py`). Меню не выполняет клики и не знает деталей UI сайтов — только управляет настройками, вызывает функции режимов и создаёт/останавливает подпроцесс генерации.

---

## 1. Назначение консольного меню

- Показать текущую конфигурацию: выбранный сайт, режим, файл промптов.
- Дать пользователю выбрать:
  - сайт (например, `aistudio`);
  - режим для выбранного сайта (например, `standard`, `multiformat`);
  - файл с промптами (путь к текстовому файлу).
- Показать план генерации без запуска кликов: разбор файла, количество карточек/пар/изображений.
- Запустить генерацию в подпроцессе и сообщить пользователю, что для экстренной остановки нужно нажать Esc.
- Обеспечить точку доступа к текущему подпроцессу для обработчика Esc (жёсткий стоп через `Process.terminate()`).

---

## 2. Ключи настроек (settings)

Меню читает и записывает в переданный словарь `settings` следующие ключи (имена — по соглашению реализации):

| Ключ           | Тип | Описание                                                       |
| -------------- | --- | -------------------------------------------------------------- |
| `CURRENT_SITE` | str | Идентификатор сайта (например, `"aistudio"`)                   |
| `CURRENT_MODE` | str | Идентификатор режима (например, `"standard"`, `"multiformat"`) |
| `PROMPTS_FILE` | str | Путь к файлу с промптами                                       |

Остальные ключи (координаты, таймауты, пороги и т.п.) могут храниться в том же словаре или в отдельном хранилище; для интерфейса меню достаточно доступа к `settings` и при необходимости к `coords`.

---

## 3. Функции верхнего уровня

### show_main_menu

```python
def show_main_menu(settings: dict, coords: dict) -> None
```

- **Назначение**: главный цикл программы — показ меню и обработка выбора пользователя до выхода.
- **Аргументы**:
  - `settings` — словарь настроек (загружается/сохраняется при необходимости при входе в пункты меню);
  - `coords` — словарь координат (передаётся в `start_generation_with_process`).
- **Поведение**: в цикле выводить текущую конфигурацию (`show_current_config`), список пунктов меню, читать ввод пользователя и вызывать соответствующую функцию:
  - **1** — `select_site(settings)`;
  - **2** — `select_mode_for_site(settings)`;
  - **3** — `select_prompts_file(settings)`;
  - **4** — `show_generation_plan(settings)` (и при необходимости `coords` — если не нужны, можно не передавать);
  - **5** — `start_generation_with_process(settings, coords)`;
  - **0** — выход из цикла (перед выходом остановить подпроцесс, если он запущен).
- При неверном вводе — сообщение и повтор показа меню.

---

### show_current_config

```python
def show_current_config(settings: dict) -> None
```

- **Назначение**: вывести в консоль текущие значения «сайт», «режим», «файл промптов».
- **Аргументы**: `settings` — словарь с ключами `CURRENT_SITE`, `CURRENT_MODE`, `PROMPTS_FILE`.
- **Поведение**: вывод строк вида «Текущий сайт: …», «Текущий режим: …», «Файл промптов: …». Если значение не задано — вывести «не выбрано» или аналог.

---

## 4. Функции выбора

### select_site

```python
def select_site(settings: dict) -> None
```

- **Назначение**: предложить пользователю выбрать сайт из списка доступных и записать выбор в `settings["CURRENT_SITE"]`.
- **Аргументы**: `settings` — словарь для записи результата.
- **Поведение**: вывести нумерованный список доступных сайтов (например, из константы или регистра: `["aistudio"]`). Прочитать номер выбора, проверить корректность, записать соответствующий идентификатор в `settings["CURRENT_SITE"]`. При неверном вводе — сообщение, без изменения настроек.

---

### select_mode_for_site

```python
def select_mode_for_site(settings: dict) -> None
```

- **Назначение**: предложить выбрать режим для текущего сайта и записать в `settings["CURRENT_MODE"]`.
- **Аргументы**: `settings` — должен содержать `CURRENT_SITE`.
- **Поведение**: по значению `settings["CURRENT_SITE"]` определить список режимов (например, для `aistudio` — `["standard", "multiformat"]`). Вывести нумерованный список, прочитать выбор, записать идентификатор режима в `settings["CURRENT_MODE"]`. Если сайт не выбран — сообщить «Сначала выберите сайт» и выйти.

---

### select_prompts_file

```python
def select_prompts_file(settings: dict) -> None
```

- **Назначение**: предложить пользователю ввести путь к файлу промптов и записать в `settings["PROMPTS_FILE"]`.
- **Аргументы**: `settings` — словарь для записи пути.
- **Поведение**: запрос пути (например, `input("Путь к файлу промптов: ")`). Опционально — проверка существования файла. Записать введённую строку в `settings["PROMPTS_FILE"]`. Пустая строка может трактоваться как «не менять» или «очистить» — по соглашению реализации.

## 5. Функции плана и запуска

### show_generation_plan

```python
def show_generation_plan(settings: dict) -> None
```

- **Назначение**: разобрать файл промптов выбранным режимом и вывести сводку (карточки, пары, планируемое число изображений) без запуска генерации и без кликов.
- **Аргументы**: `settings` — должен содержать `CURRENT_SITE`, `CURRENT_MODE`, `PROMPTS_FILE`.
- **Поведение**:
  1. Проверить, что сайт, режим и файл заданы; иначе — сообщение и выход.
  2. По `CURRENT_SITE` и `CURRENT_MODE` импортировать соответствующий модуль режима (например, `sites.aistudio.mode_standard` или `mode_multiformat`).
  3. Вызвать `load_tasks_from_file(settings["PROMPTS_FILE"])` → список задач.
  4. Вызвать `get_plan_info(tasks)` → словарь сводки.
  5. Вывести в консоль поля сводки (например, «Карточек: …», «Пар: …» (для multiformat), «Будет сгенерировано изображений: …»).
- Ошибки (файл не найден, пустой список задач) — обработать сообщением, не падать.

---

### start_generation_with_process

```python
def start_generation_with_process(settings: dict, coords: dict) -> None
```

- **Назначение**: запустить генерацию в отдельном процессе; сохранить ссылку на процесс для последующего жёсткого завершения по Esc.
- **Аргументы**:
  - `settings` — `CURRENT_SITE`, `CURRENT_MODE`, `PROMPTS_FILE` и при необходимости другие параметры для режима;
  - `coords` — словарь координат для передачи в `run_mode`.
- **Поведение**:
  1. Проверить наличие сайта, режима и файла промптов; при отсутствии — сообщение и выход.
  2. Импортировать модуль режима по `settings["CURRENT_SITE"]` и `settings["CURRENT_MODE"]`.
  3. Вызвать `load_tasks_from_file(settings["PROMPTS_FILE"])` → `tasks`.
  4. При необходимости вывести краткую сводку плана (карточки/пары/изображений).
  5. Создать объект `multiprocessing.Process` с `target=run_mode`, аргументы `(tasks, coords, settings)`.
  6. Запустить процесс (`process.start()`).
  7. Сохранить ссылку на процесс в месте, доступном обработчику Esc (глобальная переменная модуля, либо объект, передаваемый при регистрации горячих клавиш — по соглашению реализации).
  8. Вывести сообщение: «Генерация запущена. Нажмите Esc для экстренной остановки.» (или аналог).
- Не блокировать главный поток на завершение процесса: меню продолжает работать; завершение подпроцесса — по Esc или при следующем запуске (перед новым стартом проверять и при необходимости останавливать старый процесс).

## 6. Взаимодействие с обработчиком Esc (протокол)

- **Кто вызывает**: код, обрабатывающий нажатие Esc (например, регистрация горячей клавиши в отдельном модуле или потоке).
- **Что нужно**: возможность жёстко завершить текущий подпроцесс генерации.
- **Протокол**:
  1. Обработчик Esc запрашивает у консольного меню (или у общего хранилища состояния) ссылку на текущий процесс генерации.
  2. Если процесс существует и `process.is_alive()` — вызвать `process.terminate()`, затем `process.join(timeout=1.0)` (или аналогичный короткий таймаут).
  3. Вывести сообщение об экстренной остановке.
  4. Очистить/обнулить сохранённую ссылку на процесс, чтобы следующий запуск создал новый процесс.

Конкретная реализация (глобальная переменная в `console_menu.py`, передача колбэка в меню, общий «process holder») в интерфейсе не фиксируется — важно, что меню обеспечивает сохранение ссылки на процесс после `start_generation_with_process`, а обработчик Esc получает к ней доступ и вызывает `terminate()` без проверки флагов внутри подпроцесса.

---

## 7. Зависимости консольного меню

- Модули режимов сайтов (например, `sites.aistudio.mode_standard`, `sites.aistudio.mode_multiformat`) — только вызовы `load_tasks_from_file`, `get_plan_info`, `run_mode`.
- `multiprocessing.Process` — для запуска подпроцесса.
- Ввод/вывод — стандартные `print`, `input`.
- Не требуется: `pyautogui`, знание координат или деталей UI сайта (кроме передачи `coords` и `settings` в `run_mode`).
