# Сценарий пользователя

Пошаговое руководство для нового пользователя: от установки до первой генерации.

---

## 1. Требования

### 1.1. Программное обеспечение

- Windows 10/11
- Python 3.9+
- Google Chrome (или другой браузер)
- Аккаунт Google AI Studio

### 1.2. Разрешение экрана

- Рекомендуется: 1920×1080 или выше
- Масштаб Windows: 100%
- Масштаб браузера: 100%

---

## 2. Установка

### Шаг 1: Скачать проект

```bash
git clone <repository-url>
cd auto-gen-v2
```

### Шаг 2: Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 3: Проверить структуру папок

```
auto-gen-v2/
├── main.py
├── data/
│   └── (пусто или settings.json)
└── ...
```

---

## 3. Первоначальная настройка

### Шаг 1: Открыть AI Studio

1. Откройте браузер
2. Перейдите на https://aistudio.google.com/
3. Войдите в аккаунт Google
4. Откройте любой чат (или создайте новый)

### Шаг 2: Расположить окна

1. Браузер: на весь экран или фиксированный размер
2. Консоль программы: видима (можно на втором мониторе)
3. **Важно**: Не меняйте размер и положение браузера после настройки!

### Шаг 3: Запустить программу

```bash
python main.py
```

Появится меню:

```
============================================================
        АВТОМАТИЗАЦИЯ ГЕНЕРАЦИИ ИЗОБРАЖЕНИЙ v2
============================================================

[НАСТРОЙКИ]
  Сайт:    aistudio
  Режим:   standard
  Файл:    (не выбран)

[ДЕЙСТВИЯ]
  1. Выбрать сайт
  2. Выбрать режим
  3. Выбрать файл промптов
  4. Настроить параметры
  5. Настроить координаты (Ctrl+0)
  6. Настроить окно (Ctrl+Shift+V)
  7. Показать план генерации
  8. ЗАПУСТИТЬ ГЕНЕРАЦИЮ
  0. Выход

Выберите действие:
```

### Шаг 4: Настроить координаты

1. Нажмите `Ctrl+0`
2. Выберите координату (например, `1` для PROMPT_INPUT)
3. Наведите курсор на нужный элемент в браузере
4. Нажмите `Ctrl+Shift+P`
5. Повторите для всех координат

**Минимально необходимые координаты**:

- PROMPT_INPUT
- IMAGE_LOCATION
- NEW_CHAT_BUTTON
- CHAT_NAME_INPUT
- TO_SAVE_OPTION

### Шаг 5: Настроить окно

1. Убедитесь, что браузер с AI Studio активен
2. Нажмите `Ctrl+Shift+V`
3. Программа найдёт и запомнит окно

---

## 4. Подготовка файла промптов

### Шаг 1: Создать файл

Создайте текстовый файл в папке `data/`, например `my_prompts.txt`.

### Шаг 2: Заполнить файл

**Для режима standard**:

```
Карточка 1 - Промпт 1: A cute cat sitting on a windowsill
Карточка 1 - Промпт 2: A fluffy kitten playing with yarn
Карточка 2 - Промпт 1: A majestic lion in the savanna
```

**Для режима multiformat**:

```
Карточка 1 лицо Кошка - Промпт 1: A cute cat, illustration style
Карточка 1 оборот Кошка - Промпт 1: Cat anatomy diagram
Карточка 2 лицо Лев - Промпт 1: A majestic lion
Карточка 2 оборот Лев - Промпт 1: Lion habitat map
```

### Шаг 3: Выбрать файл в программе

1. В меню выберите `3. Выбрать файл промптов`
2. Введите номер файла из списка

---

## 5. Запуск генерации

### Шаг 1: Проверить план

1. Выберите `7. Показать план генерации`
2. Убедитесь, что всё верно:

```
============================================================
                    ПЛАН ГЕНЕРАЦИИ
============================================================

[ПЛАН] Режим: standard
[ПЛАН] Файл промптов: data/my_prompts.txt
[ПЛАН] Диапазон карточек: 1-2
[ПЛАН] Всего карточек: 2
[ПЛАН] Всего генераций: 3
[ПЛАН] Время ожидания генерации: 20.0 сек

Продолжить? (y/n):
```

### Шаг 2: Запустить

1. Введите `y` для подтверждения
2. Или выберите `8. ЗАПУСТИТЬ ГЕНЕРАЦИЮ` в меню

### Шаг 3: Не трогать компьютер!

- Программа будет кликать по экрану
- Не двигайте мышь
- Не переключайте окна
- Для остановки нажмите `Esc`

## 7. Остановка

### Нормальное завершение

Программа завершится автоматически после обработки всех карточек.

### Экстренная остановка

Нажмите `Esc` — воркер будет **мгновенно** остановлен.

### После остановки

1. Закройте открытые диалоги в браузере (если есть)
2. Проверьте, какие файлы успели сохраниться
3. Можно запустить генерацию заново с нужной карточки

## 8. Типичный рабочий процесс

```
1. Подготовить файл промптов
           │
           ▼
2. Запустить программу (python main.py)
           │
           ▼
3. Выбрать файл промптов (действие 3)
           │
           ▼
4. Настроить координаты (Ctrl+0) — только первый раз
           │
           ▼
5. Настроить окно (Ctrl+Shift+V)
           │
           ▼
6. Проверить план (действие 7)
           │
           ▼
7. Запустить генерацию (действие 8)
           │
           ▼
8. Ждать завершения (или Esc для остановки)
           │
           ▼
9. Проверить результаты в папке загрузок
```

---

## 9. Советы

### Перед длинной сессией

- Убедитесь, что компьютер не уйдёт в сон
- Отключите уведомления (могут перекрыть браузер)
- Проверьте место на диске

### Для стабильности

- Не открывайте другие программы во время работы
- Не подключайте/отключайте мониторы
- Используйте проводное соединение (Wi-Fi может прерываться)

### При проблемах

- Проверьте координаты (Ctrl+0)
- Перенастройте окно (Ctrl+Shift+V)
- Посмотрите логи в `logs/auto-gen.log`
- См. TROUBLESHOOTING.md

## 10. Горячие клавиши (шпаргалка)

| Клавиша        | Действие                      |
| -------------- | ----------------------------- |
| `Ctrl+0`       | Меню настройки координат      |
| `Ctrl+Shift+P` | Захватить координату курсора  |
| `Ctrl+Shift+V` | Настроить окно браузера       |
| `Esc`          | Остановить генерацию          |
| `Ctrl+1`       | Настроить START_FROM_CARD     |
| `Ctrl+3`       | Настроить GENERATION_WAIT     |
| `Ctrl+4`       | Вкл/выкл проверку изображения |
| `Ctrl+5`       | Показать текущие настройки    |
| `Ctrl+6`       | Настроить END_CARD            |
| `Ctrl+9`       | Настроить соотношения сторон  |
