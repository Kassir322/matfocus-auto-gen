# Руководство разработчика

## Рабочая архитектура

- `main.py` — точка входа для интерактивного запуска, меню и agent CLI.
- `ui/` — консольная инструкция, меню и горячие клавиши.
- `sites/aistudio/` — браузерные и API-режимы Google AI Studio.
- `utils/settings_store.py` и `utils/coordinates_store.py` — хранилища v2.
- `utils/process_control.py` — единственный слой управления воркер-процессом.
- `tests/` — контрактные тесты активного кода.

## Правила изменений

1. Не создавайте отдельные слои настроек, координат или процессов.
2. Для нового сайта добавляйте модули в `sites/<сайт>/`, затем подключайте их
   в меню и точке входа.
3. Изменения agent CLI отражайте в `version2/reference/AGENT_CLI.md`.
4. Проверяйте изменения целевыми контрактными тестами.

## Данные

`data/settings.json` не содержит API-ключей. Ключи берутся из окружения или
локального `.env`. Результаты генераций и журналы не отслеживаются Git.
