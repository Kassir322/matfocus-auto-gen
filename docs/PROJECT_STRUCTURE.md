# Структура проекта

Актуальная структура рабочего API-приложения.

```
matfocus-auto-gen/
├── main.py                         # Точка входа: меню и agent CLI
├── ui/                             # Консольное API-меню
├── sites/aistudio/                 # Единственный API-режим
├── utils/                          # API, настройки, пути и логи
├── data/                           # Настройки и локальные входные данные
├── tests/                          # Контрактные тесты активного v2
├── docs/reference/                 # Актуальные контракты и руководства
├── docs/                           # Журнал развития, карта структуры и копия навыка
└── requirements.txt                # Зависимости Python
```

## Основные слои

| Слой | Назначение |
| --- | --- |
| `main.py` | Выбирает agent CLI, консольное меню или интерактивный запуск. |
| `ui/` | Взаимодействие с пользователем и запуск операций. |
| `sites/aistudio/` | Парсинг промптов и API-реализация единственного режима. |
| `utils/settings_store.py` | Загрузка и безопасное сохранение настроек. |
| `utils/agent_cli.py` | Машинный интерфейс `agent-plan` и `agent-run-api`. |

## Данные и результаты

- `data/settings.json` — отслеживаемые безопасные настройки без секретов.
- Файлы промптов и референсов — локальные пользовательские данные.
- `generated_images/` и `logs/` — результаты запусков, игнорируемые Git.
- API-ключи задаются в окружении или локальном `.env`.

## Границы

Генерация выполняется только синхронно через API.
