# Журналы API-запусков

Каждый запуск создаёт файл `logs/auto-gen_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.log` в UTF-8.

Перед новым запуском программа удаляет только журналы `auto-gen_*.log` старше
30 дней. Результаты изображений и остальные файлы в `logs/` не затрагиваются.

Журнал содержит план: диапазон карточек, файл промптов, размеры, соотношения
сторон, провайдеры, модели, референсы и папку результатов. Для каждой задачи
записываются запрос, результат, сохранённый файл или ошибка. В конце находится
сводка успешных и неуспешных изображений.

`API_LOG_PROMPTS=true` записывает исходный и отправленный промпты. При
`false` сохраняются только их длины. Для разового машинного запуска используйте
`--no-log-prompts`.

Ключи API, заголовки авторизации и содержимое изображений в журнал не пишутся.
