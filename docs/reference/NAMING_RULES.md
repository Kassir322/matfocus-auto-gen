# Имена результатов

Каждое изображение сохраняется в папке запуска внутри `OUTPUT_BASE_DIR`.
Имя имеет формат:

```text
Карточка_<номер>_<название>_<сторона>_промпт_<номер>_<провайдер>_<модель>.png
```

Например:

```text
Карточка_12_Австрия_лицо_промпт_1_ChatGPT_gpt-image-2.png
```

Недопустимые для имени файла символы в названии карточки заменяются на `_`.
Номер карточки, сторона и номер промпта берутся из строки входного файла.
