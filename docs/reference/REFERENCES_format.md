# Референсные изображения

`multiformat_with_refs` поддерживает два независимых типа референсов.

## Контентные референсы

Размещайте их в папках:

- `data/images/лицо` — для лица;
- `data/images/оборот` — для оборота.

Допустимые имена файлов (`png` или `jpg`):

```text
12_лицо.png
12_оборот.jpg
лицо_12_Название_карточки.png
оборот_12_Название_карточки.jpg
```

Сначала программа ищет короткое имя, затем расширенное. Отсутствие
контентного референса не является ошибкой.

## Стилевой референс

Задаётся параметром `API_STYLE_REFERENCE_IMAGE` или `--style-ref`. Он влияет
на палитру, линию, фактуру и уровень детализации, но не должен задавать сюжет.

Стилевой референс доступен только при
`API_PROVIDER_WITH_REFS=chatgpt`. Используйте `--no-style-ref`, чтобы отключить
настройку для одного машинного запуска.

Если для задачи найдены оба типа, API получает сначала стилевой, затем
контентный референс.
