# Журнал развития проекта

Этот документ фиксирует текущее состояние, ближайшие задачи и ключевые
изменения. Поведение программы определяется работающим кодом, а не журналом.

## Текущее состояние

- Программа генерирует изображения карточек только через API.
- Единственный поддерживаемый формат — `multiformat_with_refs`: лицо и оборот
  карточки, контентные референсы и необязательный стилевой референс.
- Точки входа: интерактивное API-меню (`python main.py`) и машинные команды
  `agent-plan` и `agent-run-api`.
- Удалены прежние не-API механизмы запуска.
- Машинные команды поддерживают явный фон Images API через `--background`
  без изменения локальных настроек; прозрачность запрашивается как PNG.

## История изменений

### 2026-10-29 — прозрачный фон в машинных командах

- Добавлен `--background transparent|opaque|auto` для планирования и запуска.
- Значение проходит через режим к `images.generate` и `images.edit`; для
  прозрачности явно запрашивается PNG. Отсутствие флага сохраняет старый запрос.
- Другой провайдер отклоняется до API, а локальные настройки не меняются.
- Добавлены проверки настоящих HTTP-запросов установленного OpenAI SDK через
  локальный `MockTransport`, без соединения с API и без генераций.
- Проверка: весь набор `pytest` прошёл — 48 проверок. `agent-plan` с
  текущими локальными настройками подтвердил `image_background=transparent`;
  исходные настройки и `.env` побайтно не изменились. Реальная генерация
  этим изменением не запускалась.
