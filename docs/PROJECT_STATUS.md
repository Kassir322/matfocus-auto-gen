# Журнал развития проекта

Этот документ фиксирует текущее состояние, ближайшие задачи и ключевые
изменения. Поведение программы определяется работающим кодом, а не журналом.

## Текущее состояние

- Программа генерирует изображения карточек только через API.
- Единственный поддерживаемый формат — `multiformat_with_refs`: лицо и оборот
  карточки, контентные референсы и необязательный стилевой референс.
- Точки входа: интерактивное API-меню (`python main.py`) и машинные команды
  `agent-plan` и `agent-run-api`.
- Удалены прежние не-API механизмы запуска.
