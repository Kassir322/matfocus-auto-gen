# AI Image Generator Automation (v2)

**Автоматизация генерации изображений в Google AI Studio**

Программа автоматически генерирует изображения по промптам из файла: поддерживаются стандартный режим (несколько генераций на карточку) и мультиформатный (лицо/оборот с настраиваемыми соотношениями сторон). Управление — через горячие клавиши и консольное меню.

## Быстрый старт

### Метод 1: Через браузер (Browser)

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите программу: `python main.py`
3. Настройте координаты: нажмите `Ctrl+0`, выберите пункт, наведите мышь на элемент в браузере и нажмите `Ctrl+Shift+P`
4. Выберите файл промптов в меню (или положите файл в `data/`)
5. Запустите генерацию: `Ctrl+Shift+S`. Остановка: `Esc`

Настройки и координаты хранятся в `data/settings.json` и `data/coordinates.json`.

### Метод 2: Через API (Gemini API) — НОВОЕ! ⚡

**Преимущества:** быстрее, стабильнее, не требует настройки координат и браузера.

1. Установите зависимости: `pip install -r requirements.txt`
2. Получите API ключ: https://aistudio.google.com/apikey
3. Запустите программу: `python main.py`
4. Нажмите `Ctrl+7`:
   - Выберите метод генерации → `2` (api)
   - Введите ваш API ключ (или обновите существующий)
   - Выберите режим генерации (standard/multiformat)
5. Выберите файл промптов (или положите файл в `data/`)
6. Запустите генерацию: `Ctrl+Shift+S`. Изображения генерируются напрямую через API, без браузера!

📖 **Подробнее:** [version2/reference/API_INTEGRATION.md](version2/reference/API_INTEGRATION.md)

## Горячие клавиши (для браузерного режима)

| Комбинация     | Действие                                                     |
| -------------- | ------------------------------------------------------------ |
| `Ctrl+0`       | Меню настройки координат                                     |
| `Ctrl+Shift+P` | Получить координаты курсора / сохранить выбранную координату |
| `Ctrl+Shift+V` | Настройка рабочего окна браузера                             |
| `Ctrl+Shift+S` | Старт генерации                                              |
| `Esc`          | Экстренная остановка генерации                               |
| `Ctrl+1`       | Настроить START_FROM_CARD                                    |
| `Ctrl+6`       | Настроить END_CARD                                           |
| `Ctrl+3`       | Настроить GENERATION_WAIT                                    |
| `Ctrl+8`       | Настроить IMAGE_WAIT_INTERVAL                                |
| `Ctrl+4`       | Переключить CHECK_IMAGE_GENERATED                            |
| `Ctrl+9`       | Настроить FACE_ASPECT_RATIO и BACK_ASPECT_RATIO              |
| `Ctrl+7`       | Выбрать метод генерации (browser/api) и режим                |
| `Ctrl+5`       | Показать текущие настройки и план                            |

**Примечание:** при использовании API-режима координаты и окно браузера не требуются.

## 🛠️ Разработка

### Добавление поддержки новой нейросети

1. **Создайте профиль координат** в `config/profiles/`
2. **Реализуйте генератор** на основе `core/image_generator.py`
3. **Добавьте специфическую логику** в `core/`
4. **Обновите UI** для выбора нейросети
5. **Добавьте тесты** в `tests/`

### Архитектурные принципы

- **Модульность** - каждый компонент отвечает за одну задачу
- **Конфигурируемость** - все параметры в JSON файлах
- **Расширяемость** - легко добавлять новые нейросети
- **Безопасность** - контролируемое выполнение с возможностью остановки

### Создание билда

```bash
# Установка PyInstaller
pip install pyinstaller

# Создание EXE файла
pyinstaller ai_studio_automation.spec

# Готовый файл появится в dist/
```

## 🚀 Возможности

### Два метода генерации

- **Browser** (браузерная автоматизация) — полный контроль, история чатов в AI Studio
- **API** (Gemini API) — быстрее, стабильнее, без настройки координат

### Режимы генерации

- **Standard** — стандартный режим (несколько генераций на карточку)
- **Multiformat** — мультиформатный режим (лицо/оборот с разными aspect ratio)
- **Multiformat with refs** — с референсами (только browser)

### Особенности

- Автоматическое сохранение изображений с понятными именами
- Гибкая настройка диапазона карточек
- Структурное логирование всех операций
- Поддержка различных соотношений сторон (4:3, 16:9, 1:1 и др.)
- Горячие клавиши для быстрого доступа к функциям
