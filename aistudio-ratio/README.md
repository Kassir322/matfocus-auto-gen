# Nanobanana Aspect Ratio Saver

Браузерное расширение для Chrome, которое автоматически запоминает и применяет выбранное значение Aspect Ratio в Nanobanana (Google AI Studio).

## Установка

1. Скачайте папку с расширением
2. Откройте Chrome и перейдите на `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `nanobanana-aspect-ratio`

## Использование

Расширение работает автоматически:

1. Откройте https://aistudio.google.com/prompts/new_chat
2. Выберите нужное значение Aspect Ratio (например, 16:9)
3. При следующем посещении страницы выбранное значение применится автоматически
4. Каждое новое изменение Aspect Ratio сохраняется

## Как это работает

- Расширение отслеживает изменения в селекторе Aspect Ratio
- Сохраняет последний выбор в chrome.storage.local
- При загрузке страницы автоматически применяет сохранённое значение
- Работает на всех страницах Google AI Studio

## Отладка

Чтобы увидеть логи работы расширения:
1. Откройте DevTools (F12)
2. Перейдите во вкладку Console
3. Ищите сообщения с префиксом `[Nanobanana]`
