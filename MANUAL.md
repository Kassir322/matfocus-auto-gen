# Руководство API-генератора

Приложение работает только через API в режиме `multiformat_with_refs`.

`python main.py` открывает меню выбора промптов, диапазона карточек, параметров
API, папки вывода и стилевого референса. Пункт запуска работает в текущей
консоли; остановка — `Ctrl+C`.

Контентные референсы размещаются в `data/images/лицо` и
`data/images/оборот`. Стилевой референс задаётся в меню или параметром
`--style-ref`; его отсутствие допустимо.

Для машинных запусков сначала используйте `agent-plan`, затем `agent-run-api`.
В обеих командах обязательны `--prompts` и `--output-base-dir`; параметр
`--mode` отсутствует. Подробный контракт — `docs/reference/AGENT_CLI.md`.
